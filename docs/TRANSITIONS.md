# 转换

左侧“转换”页当前提供 Smooth Slide。将卡片拖到文字、图片、视频或形状片段的左侧可添加片头转换，拖到右侧可添加片尾转换；拖到片段中部会同时添加片头和片尾。相邻片段的接点会同时高亮两侧，放下后形成一个跨接点转换。音频片段和锁定轨道不接受转换。

转换标记位于片段内部，以青色竖条和 `|||` 显示。拖动标记靠片段内侧的边缘可以调整持续时间；接点两侧的标记共享时长、启用状态和方向。片段移动后若不再相邻，接点转换会保留为两端各自独立的转换。拆分片段时只在左段保留原片头、右段保留原片尾，不在新的拆分接点生成转换。

点击转换标记会打开右侧“转换”属性页。属性页可选择类型、切换“反转”、暂时禁用或用标题栏的删除按钮移除。选中标记后按 Delete 也只删除转换，不删除片段；删除和参数修改均支持撤销、重做。接点转换的操作会同步到两侧。

Smooth Slide 使用圆滑缓入缓出曲线：正常方向下，前一个画面向左滑出，后一个画面从右侧滑入；“反转”后方向相反。接点转换以剪切点为中心，预览和视频导出在过渡区保持前一段的尾帧与后一段的首帧，因此不要求源素材具有额外把手，也不会在接点露出背景。音频仍按原始片段边界播放，不在延展区重复声音。

交互依据项目内 Camtasia 2024 英文帮助第 192–194 页的规则：拖到左端、右端或中部，拖动转换边缘调节时长，点击转换后在属性中启用、禁用或删除。当前只实现 Smooth Slide，其他转换样式以及 Camtasia 转换参数导入尚未覆盖。

`pnpm exec vitest run tests/transitions.test.ts` 验证放置规则、接点联动、项目 schema、拆分、预览截帧和真实 FFmpeg 视频的接点像素。构建后运行 `node scripts/smoke-transitions.mjs` 可验证拖放高亮、片段内标记、属性、反转、启用、时长拖动、删除、撤销和保存。
