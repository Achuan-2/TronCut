```

│ 工具要求       │   TronCut UI   │   TronCut UI   │   Node.js      │
```

### 路线详情

```
🟦 路线 A: 完全手动工作流
├─ 步骤 1: 录屏 → 25% (1-2h)
├─ 步骤 2: 导入编辑 → 50% (2-3h)
├─ 步骤 3: 配音添加 → 75% (1h)
└─ 步骤 4: 导出检查 → 100% (1-2h)
   
🟩 路线 B: 混合工作流 (推荐)
├─ CLI 抽帧 → 10% (10分钟)
├─ Claude 脚本生成 → 30% (20分钟)
├─ CLI 配音生成 → 50% (30分钟)
├─ TronCut UI 编排 → 75% (2-3h)
└─ 导出检查 → 100% (30分钟)
   
🟪 路线 C: 完全自动化
├─ 环境配置 → 20% (15分钟)
├─ 执行自动脚本 → 80% (1-2h)
└─ 检查输出 → 100% (30分钟)
```

## 🔧 技术架构图

```
┌────────────────────────────────────────────────────┐
│         TronCut 宣传视频制作技术架构                 │
└────────────────────────────────────────────────────┘

【输入层】
  ├─ 录屏素材 (MP4)
  ├─ 脚本文本
  ├─ 背景音乐
  └─ 系统设置

         ↓

【处理层】
  ┌────────────────────────────────────────┐
  │  TronCut 编辑核心                      │
  ├────────────────────────────────────────┤
  │  • 时间线引擎 (Rust)                   │
  │  • 视频合成 (FFmpeg)                   │
  │  • 音频混音 (DSP)                      │
  │  • 字幕生成 (ASR)                      │
  │  • 文字渲染 (Canvas/WebGL)             │
  └────────────────────────────────────────┘

         ↓

【特色功能层】
  ├─ 智能配音 (TTS/克隆)
  ├─ 自动字幕 (语音识别)
  ├─ 自动关键帧 (动画)
  ├─ 声音增强 (降噪/EQ)
  └─ CLI 接口 (JSON)

         ↓

【输出层】
  ├─ MP4 视频 (H.264/H.265)
  ├─ 工程文件 (JSON)
  ├─ 字幕文件 (SRT/VTT)
  └─ 音频文件 (AAC/WAV)

【可选: AI 增强】
  ┌────────────────────────────────────────┐
  │  Claude API + TronCut CLI              │
  ├────────────────────────────────────────┤
  │  • 关键帧分析 → 脚本生成              │
  │  • 配置优化 → 工作流自动化             │
  │  • GitHub Actions 集成                │
  └────────────────────────────────────────┘
```
