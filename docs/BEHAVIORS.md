# 行为

左侧“行为”提供切换、弹出、摆动、逐字显示、淡入淡出、滑动、漂移、爆炸、缩放、脉动、跳起和下落、颤动、波浪等预设。悬停卡片可预览，拖到时间线或画布中的文字、字幕、图片、视频、形状上即可应用；也可双击应用到所选片段。文本行为可叠加；从预设添加新的媒体行为时，会自动移除片段上的旧行为，只保留新行为。文字预设应用到非文本片段时会转换为媒体行为，同样采用替换方式。

点击片段底部箭头展开效果条，行为和剪辑速度都显示在片段边框内部的底部区域，多个效果向下排列；展开时片段和轨道一起增高，收起时恢复。点击行为条将选中它，并打开右侧“行为”属性页；选中条为黄色。按 Delete 只删除该行为，保留片段。右键行为条可复制效果、粘贴效果和删除，复制后也可右键其他片段选择“粘贴效果”，或使用 Ctrl+C / Ctrl+V。修改支持撤销和重做。属性标题可展开或收起，开关可暂时禁用，更多菜单提供复制、重置和删除。

属性按“进／期间／出”分开设置。“对象”处理整个图层；文字额外提供“文本”子菜单，可选择第一个到最后一个、最后一个到第一个、从中间向两侧。每个阶段可以选择样式和缓动；进出阶段调整方向、速度与逐字偏移，期间阶段调整强度、循环时间、循环间延迟、次数或永远循环。样式为“无”时关闭该阶段。

行为条覆盖片段全长，时长随片段调整；不提供独立裁短或拖动范围。行为独立于原有变换关键帧，项目保存会保留所有参数。画布预览、视频导出和截帧均支持对象行为和逐字行为。

## 切换

“切换”是位移动效：进场先移入并跳跃回弹，期间按设定循环平移，出场按缓动移出。视频、图片和形状整体运动；文本可按字符处理，并提供“中心向外”和“同时”等类型。进出阶段选择“跳跃”时显示张力，其他移动方式显示速度；期间阶段显示平移、循环时间、延迟、循环次数和永远循环。文本类型额外显示偏移，对象不显示文本类型或偏移，切换不显示方向字段。

默认按截图设置：进场采用跳跃、张力 7.00；期间采用缓出圆曲线、平移 5.00、循环时间 3.17 秒；出场采用缓出指数曲线、速度 93%。文本默认进出为中心向外，偏移分别为 0.02 和 0.03 秒，期间为同时。切换的张力、平移与循环参数均参与实际预览、截帧和导出。文字与对象的精确运动距离由本项目坐标模型实现，未宣称与 Camtasia 的私有曲线和距离逐帧相同。

## 对照依据与验证

交互参考用户提供的 Camtasia 中文截图，以及 TechSmith [Camtasia 9/3 官方帮助](https://www.techsmith.com/learn/wp-content/uploads/2022/01/Camtasia-9.1_3.1-Help.pdf) 第 59–60 页、[Camtasia 2022 官方帮助](https://www.techsmith.com/blog/wp-content/uploads/2023/12/Camtasia-Help-2022-EN.pdf) 第 177–178 页。后者列出期间阶段的强度、循环时间、延迟、次数和永远循环。官方[效果操作说明](https://www.techsmith.com/blog/video-effects/)也说明悬停预览、拖到媒体、效果抽屉和叠加。

目前按公开说明实现交互和参数含义，动效曲线由本项目实现；不宣称与 Camtasia 私有预设逐帧一致，也不提供 Camtasia 行为导入兼容。逐字视频导出缓存字符位图与重复姿态，静止部分复用图像；长时间持续逐字动效的导出仍需要额外 CPU 和临时文件。

`pnpm exec vitest run tests/behaviors.test.ts tests/behaviors-export.test.ts` 验证字符分组、时序、对象变换、项目往返与真实媒体输出。构建后运行 `node scripts/smoke-behaviors.mjs` 可在独立桌面测试项目中检查文字／图片／视频、类型分级菜单、三阶段、循环、开关、效果复制粘贴、删除、撤销和保存，并在 `test-output/` 下保留截图。
