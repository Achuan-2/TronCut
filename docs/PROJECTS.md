# 工程管理

## 保存与迁移

首次保存时选择父目录，TronCut 自动新建独立工程文件夹。整个目录可复制或移动，重名目录会增加后缀，媒体使用相对路径。TronCut 同时支持读取旧 `.framecraft` 工程，新工程使用 `.troncut`。

## 工程文件

```text
我的视频/
├── 我的视频.troncut       # 可读 JSON：画布、轨道、片段、动画
├── media/
│   ├── <ID>-录屏.mp4
│   ├── <ID>-旁白.wav
│   └── <ID>-cursor.json   # 独立鼠标轨迹
├── project.ico           # Windows 文件夹图标
└── desktop.ini
```

工程目录会收集媒体和鼠标轨迹；文本框、自动字号和运镜关键帧保存在工程正文中。生成的配音 WAV 和配音参数也随工程保存，详见 [本地配音](TTS.md)。素材离线时，可通过 [素材重链接](MEDIA.md#素材重链接) 恢复引用。
