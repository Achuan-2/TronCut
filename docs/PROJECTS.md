# 项目管理

## 首页与最近项目

软件普通启动进入首页，不自动载入上次编辑。首页提供新建录制、新建项目、打开项目和最近项目；新建项目是空白项目，新建录制先建立空白项目再打开录制面板。从系统双击 `.troncut`/`.framecraft` 文件启动时，仍直接打开指定项目。

最近项目记录已打开或保存的项目，按最近使用排序、去重，最多保留 20 项，并在重启后保留。卡片显示项目名称、修改日期、项目 JSON 大小、时间线时长和路径；有图片/视频素材时使用可见轨道中的素材缩略图，没有媒体时显示默认图标。文件已移动或删除时显示缺失标记并禁止打开，可右键选择“从最近项目中移除”，只移除历史记录；也可用“打开项目”重新定位。移除结果在重启后保留。

右键最近项目可选择“另存为…”或“打开项目位置”，后者在系统文件管理器中选中项目文件。另存当前编辑的项目会包含尚未保存的修改；另存其他项目时，保留当前编辑会话。

首次使用带首页的版本时，若旧恢复记录包含仍存在的已保存项目，会将它加入最近项目，但不会自动恢复其编辑。上次未保存的内容在首页单独显示“恢复编辑”，点击后才载入。编辑器左上角的“返回首页”暂停播放并保留当前编辑会话；首页“继续编辑”返回原会话，不丢弃未保存修改。打开其他项目或新建时，当前会话有未保存内容会先提示。

## 保存与迁移

新建项目和新建录制会直接在系统“文档”目录的 `TronCut/Projects` 下建立独立项目文件夹，无需选择保存路径。同名项目自动增加编号，例如 `未命名项目-2/未命名项目-2.troncut`。点击“保存”或按 `Ctrl+S` 将当前修改和素材写入项目目录；尚未保存过的导入项目也默认保存到该位置。

“编辑 → 首选项 → 程序 → 存储 → 默认项目创建位置”可更改上述默认目录，并支持恢复默认。设置保存后用于后续新建及首次保存，已有项目仍在原位置保存。自动恢复备份的位置可在同一分组的“备份文件夹”中单独设置。

需要指定位置时，右键编辑器顶部的项目名称或首页最近项目，选择“另存为…”；也可使用项目菜单或 `Ctrl+Shift+S`。TronCut 按选定名称新建独立项目文件夹并收集素材，保留原项目。整个目录可复制或移动，重名目录会增加后缀，媒体使用相对路径。TronCut 同时支持读取旧 `.framecraft` 项目，新项目使用 `.troncut`。

## 项目文件

```text
我的视频/
├── 我的视频.troncut       # 可读 JSON：画布、轨道、片段、动画
├── media/
│   ├── <ID>-录屏.mp4
│   ├── <ID>-旁白.wav
│   └── <ID>-cursor.json   # 独立鼠标轨迹
└── desktop.ini           # Windows 文件夹图标，引用软件安装目录中的图标
```

项目目录会收集媒体和鼠标轨迹；文本框、自动字号和运镜关键帧保存在项目正文中。生成的配音 WAV 和配音参数也随项目保存，详见 [本地配音](TTS.md)。素材离线时，可通过 [素材重链接](MEDIA.md#素材重链接) 恢复引用。

Windows 的 `desktop.ini` 直接引用安装目录中 `resources/project.ico` 的绝对路径，不再向每个项目复制图标；开发环境引用源码目录中的 `resources/icon.ico`。旧版默认配置会在再次保存时更新，并删除与当前软件图标内容一致的旧副本，已有自定义文件夹配置保留。迁移项目到其他电脑后，媒体仍可正常读取；文件夹图标依赖原引用路径存在。
