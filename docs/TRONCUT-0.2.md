# TronCut 0.2 交付记录

本版是在现有录制—剪辑—项目归档—MP4 导出链路上继续开发的可运行版本，不将尚未实现的功能列为“完整版”。旧项目可以读取；新建和新保存使用 `.troncut` 与 `format: "troncut"`，schema 版本仍为 1，以可选字段扩展。

## 核心实现

- Windows WGC 原生录制与独立鼠标采样：15/30/60 fps，暂停/恢复，不将光标烧入画面；后期修改形状/颜色/大小，隐藏、平滑与点击高亮。鼠标随裁剪、速度及画面变换输出，保存为项目目录内独立 JSON。
- 多选、同步移动、组合/解组、批量复制/粘贴/拆分、波纹删除。波纹删除只移除其他片段未占用的删除区间，锁定轨道保持位置。
- 裁切、旋转、亮度、对比度、饱和度、黑白、模糊、翻转及淡入淡出。属性面板与 FFmpeg 输出共用效果数据。
- 媒体缩略图、音频概览波形、时间线可视区渲染；生成缩略图的解码任务串行排队，避免同时打开大量解码器。
- 离线素材重链接，验证替换类型与源区间长度；保持原 ID、片段、动画和轨道。
- SenseVoice 真实中文 CPU 转录通过；缓存模型直接使用本地路径，减少重复仓库请求。Windows 包附带 uv，Python 安装和缓存放在应用数据目录。

## 已修复的实际问题

Windows 将 `desktop.ini` 标为系统隐藏后再次用覆盖模式写入会失败。现在仅在不存在时创建，不重写既有文件夹自定义内容，并增加带图标的重复保存回归。

鼠标导出曾因 FFmpeg framesync 预读，提前应用末帧坐标。将鼠标命令放在当前画面合成之后，为下一帧设置位置，增加实际像素位置测试。点击高亮保持在原始点击位置。

取消任务使用拥有的工作进程 PID 终止子进程树，防止只退出 uv 而遗留 Python 推理；不通过 shell 执行字符串命令。
