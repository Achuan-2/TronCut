### 第五阶段：音频处理 (Week 3-4)

#### 5.1 配音导入与同步
- [ ] 导入所有配音段
- [ ] 将配音与对应的视频段对齐
- [ ] 检查配音与视频是否同步
- [ ] 调整配音的音量（推荐：-3dB 到 0dB）

#### 5.2 背景音乐处理
- [ ] 导入背景音乐
- [ ] 设置音乐音量为 0.3-0.4（不盖过配音）
- [ ] 为音乐添加淡入淡出（各 5 秒）
- [ ] 调整音乐长度与整个视频长度一致

#### 5.3 音频混音
- [ ] 配音轨音量：-0.5 到 0 dB
- [ ] 背景音乐音量：-15 到 -18 dB（相对于配音）
- [ ] 测试整体音量，确保不过载（峰值不超过 -3dB）
- [ ] 添加降噪处理（如需要）

#### 5.4 音效添加（可选）
- [ ] 添加转场音效
- [ ] 添加按钮点击音效
- [ ] 添加成功提示音
- [ ] 调整音效音量

- [ ] 应用最后的均衡处理

## 🎬 质量检查清单（导出前）

## 📞 遇到问题

### 常见问题排查

**Q: 导出太慢？**
- A: 尝试使用硬件编码器（NVIDIA NVENC 或 AMD VCE）
- 检查电脑是否有足够的 RAM 和存储空间
- 降低导出比特率测试

**Q: 视频卡顿？**
- A: 检查所有媒体是否成功导入
- 降低预览分辨率
- 关闭不需要的效果再测试

**Q: 音视频不同步？**
- A: 检查所有片段的时码
- 手动调整配音和视频的起始时间
- 重新导出

**Q: 文字显示不全？**
- A: 减小字号或缩短文字内容
- 调整文字框的大小和位置
- 检查文字所在的轨道是否被其他元素遮挡
