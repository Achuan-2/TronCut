本版完善素材库与工程管理，新增画布选框旋转和箭头控制，并改进属性滑杆、裁剪缩放与播放头范围标记。

## 更新内容

- **素材管理**：素材库新增文件夹和右键管理，便于整理与复用素材；支持从外部直接拖入文件到项目媒体。
- **工程归档**：新建工程默认保存到项目目录，支持右键另存为和定位工程文件夹。
- **画布编辑**：支持拖动选框旋转对象，拖动箭头端点并调整弯曲程度。
- **长时间线**：扩大时间轴缩小范围，优化长时间工程的标尺显示。
- **属性滑杆**：参考 Camtasia 将滑杆与数值输入框分开，加宽滑动区域并显示轨道进度；裁剪模式下框内画面缩放最低为 100%。
- **播放头与范围标记**：缩小左右范围标记并改进悬停反馈，修复播放至时间线右侧时标记与播放头错位的问题。
- **项目文档**：移除中英文 README 的赞赏图片、链接和导航入口。

完整改动见[更新日志](https://github.com/Achuan-2/TronCut/blob/v0.5.8/CHANGELOG.md)。
