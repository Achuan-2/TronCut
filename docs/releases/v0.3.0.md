# TronCut v0.3.0 · 编辑体验与本地配音

本次为 Windows x64 预发布，重点改进画布、文本与时间线动画编辑，并加入本地文本转语音。

## 编辑体验

- 轨道统一为“轨道1、轨道2……”的通用轨道，可放置文字、图片、视频和音频。粘贴图片或截图时，每张图片默认新增顶部轨道。
- 支持粘贴系统图片、截图和视频文件直接加入时间线；滚动轨道时，顶部时间刻度尺保持可见。
- 动画以起点、箭身、终点显示实际时长。拖动圆点调整开始或结束，拖动箭身整体移动，支持按帧对齐、边界限制、轨道锁定和撤销。
- 自动动画默认持续 1 秒，以当前播放头为终点，保留动画之间的静止间隔；已有相连箭头也可拖开。编辑圆点放大，退出后恢复。编辑后一段起点会修改前一段终点；第一段起点修改初始属性，不额外生成开头动画。
- 点击动画起点或终点进入该关键帧编辑状态。关闭“自动动画”时，修改位置、缩放、不透明度、旋转或画布拖拽也只修改选中的帧，修复终点修改导致整段画面一起改变的问题。
- 图片、视频可通过画布八个手柄等比调整尺寸；“缩放与平移”面板可调整整个画面的取景并自动记录运镜关键帧，项目保存和 MP4 导出保留动画。
- 双击画布或时间线文本直接编辑多行文字。独立“文本”属性页支持“自动调整文本大小”，拖动文本框自动适配字号。
- 画面属性页精简为缩放、不透明度、旋转、位置、宽高和水平/垂直翻转；时间、速度和声音设置放入独立“片段”页。鼠标属性放入录屏的独立标签页。
- 紧凑标题栏与自绘窗口按钮减少顶部占用，保留未保存项目退出确认。界面统一使用 TronCut，花字模板显示“花字”。
- 统一循环图片、鼠标和点击光圈的输入设置，修复多段文字及录屏鼠标导出可能停滞的问题。

## 本地配音

新增 Kokoro 中文版、Qwen3-TTS 0.6B/1.7B 与 IndexTTS 2.5。支持文稿读取、音色与设备选择、语速、试听、取消、时间线插入和配音参数保存。IndexTTS 可使用参考音频；参考素材随项目归档。

首次使用需要联网下载 Python、依赖与模型，文稿在本机合成。已准备的环境和模型可用于离线生成；已有配音项目的打开、播放与导出无需加载模型。Kokoro CPU 与 IndexTTS 在 RTX 4050 上的短样本离线合成已验证；Qwen、Mac、长文稿与真人参考音色质量仍待验证。详细说明见 [本地配音](../TTS.md) 和 [IndexTTS](../INDEXTTS.md)。

## 验证与范围

类型检查、构建、89 项 TypeScript 测试、18 项 Python 辅助逻辑测试及 Electron 桌面回归通过，详细记录见 [验证记录](https://github.com/Achuan-2/TronCut/blob/v0.3.0/docs/VALIDATION.md)。真实 FFmpeg 测试覆盖关键帧左右位置、旋转、运镜、多行文字、字号、声音与项目保存重开；桌面回归覆盖动画端点编辑与拖动、撤销、锁定、文本框、媒体粘贴和窗口控制。

旧 `.troncut`、`.framecraft` 项目继续支持；旧轨道名称统一编号，保留素材引用、片段顺序、动画及锁定/静音状态。Windows 构建未配置代码签名。Mac 安装包、完整 Camtasia/TREC 导入、长录屏、多设备同步、大型项目性能、完整效果库及交互输出仍待开发或验收。
