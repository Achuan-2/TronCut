本版加入录屏自动美化、LuxTTS 声音克隆和更完整的导出设置，改善本地语音模型重复加载的速度，并重新整理编辑菜单与首选项。

## 更新内容

- **录屏自动美化**：录制前选择渐变背景、留白和圆角，录制后自动添加独立背景轨道。Windows 原生录屏支持调整鼠标样式、大小、颜色、平滑与点击高亮，根据点击和停留生成可继续编辑的聚焦缩放。
- **LuxTTS ONNX 声音克隆**：导入参考音频或直接录音，识别并校对参考文字，保存到本机音色库后重复试听和配音。另新增 Windows 系统语音，优先使用本机云希。
- **ONNX 模型常驻缓存**：字幕识别、配音和试听复用常驻推理进程与内存模型，减少重复加载；支持任务排队、取消和异常后重启。移除 Qwen3-ASR CUDA 入口，保留 INT8 CPU 与 SenseVoiceSmall。
- **导出设置弹窗**：默认输出到项目所在目录，支持指定位置、分辨率、质量及 MP4、MOV、MKV、WebM 格式，包含覆盖确认和取消清理。
- **编辑菜单与分组首选项**：补全常用剪辑操作；首选项移入“编辑”，支持 Ctrl/⌘+, 打开。程序、计时、快捷键、项目、AI 模型和高级分组可设置默认工具、各类素材时长、新项目规格及录屏鼠标等选项。
- **同一服务使用多个 AI 模型**：填写一次 API 地址和密钥，即可获取模型列表、搜索、多选添加及切换模型，兼容已有配置。
- **字幕与画布细节**：默认字幕描边改为 5，新增文本背景开关和浮动搜索替换；改善画布、时间线快捷缩放与画布外素材编辑，修复文字导出描边锯齿和长素材名称撑宽属性面板。

安装包包含对应平台的 FFmpeg、FFprobe 与 uv；首次使用本地语音功能需联网下载运行环境和模型，之后可在本地运行。模型缓存保留在当前应用进程内，退出应用后再次使用仍需首次加载。

Windows 原生录屏的独立鼠标轨迹用于鼠标编辑与自动缩放；兼容录屏可添加背景，但不具备独立鼠标轨迹。macOS 包未签名、未公证，也未经真机功能验收，安装、权限、录制和导出由使用者自行验证。

高分辨率录屏叠加自动缩放和圆角时，目前仍由 CPU 合成，导出可能明显变慢；硬件编码不代表全流程 GPU 加速。

TronCut 项目源码由 GitHub 标签的 Source code 提供；FFmpeg 上游源码作为第三方分发材料保留。
