# TronCut v0.4.1

本版改进字幕、文字动效和多轨编辑，支持直接对已有字幕重新断句，无需再次识别语音。

## 更新内容

- 字幕面板支持导入导出、直接编辑、搜索替换、整轨样式与位置调整，以及转为普通文本。重复识别自动创建新字幕轨道。
- 默认使用 Qwen3-ASR 0.6B 全局识别时间线，保留 SenseVoiceSmall。新增标准、AI、自定义字数和不限制长度四种断句方式，支持 AI 纠错与润色；顶部首选项可设置 OpenAI 兼容接口。
- 字幕默认字号为 40，背景默认黑色、75% 不透明度、左右 12px 与上下 6px 内边距、6px 圆角。文本和字幕的背景均可调整，应用样式模板保留原字号。
- 轨道右键支持插入、移动、移除、清理空轨、重命名、全选媒体、隐藏、独奏和锁定。独奏同时作用于预览、导出和识别音频，操作支持撤销。
- 新增文字、图片和视频行为动效，以及支持片头、片尾和接点的 Smooth Slide 转换。
- 整合旁白录音与 AI 文本配音；提供供 Codex 调用的剪辑、配音、字幕及导出 CLI。
- 修复暂停后继续播放卡顿、轨道滚动不同步、首选项输入框过窄和剪辑速度显示精度。
