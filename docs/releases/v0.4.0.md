# TronCut v0.4.0 · ONNX 语音与剪辑体验

本次发布提供 Windows x64、Apple Silicon Mac 与 Intel Mac 安装包。Windows 包已完成桌面回归；Mac 包未经真机验证，由使用者自行测试。

## 本地语音与模型下载

- 语音转字幕统一使用 sherpa-onnx，提供 SenseVoiceSmall 多语言与 Paraformer 中文 ONNX 模型；字幕按真实词时间戳或语音段生成，并与片段裁剪和变速对齐。
- 文本转语音使用 Kokoro 中英文与 VITS 中文 ONNX 模型，提供预设音色、语速调节、试听及时间线插入，当前使用 CPU。
- 字幕和配音面板提供模型下载按钮；首次生成缺少模型时自动下载，显示下载进度并支持取消。模型保存在 TronCut 自己的缓存，也可指定完整模型目录。
- 提供严格离线选项，下载完成后可离线生成；配音文稿、模型、音色与语速随项目保存。

## 剪辑与标注

- 新增剪辑速度视觉效果，可拖入视频或音频片段；时间线效果条与属性中的倍速、持续时间联动。
- 文本、形状和箭头统一进入“标注”面板，支持点击添加与拖入画布、时间线。
- 改进轨道拖动、轨道显示、动画与关键帧操作，优化时间线旁的快捷按钮。

## 下载

- `TronCut-Setup-0.4.0-windows-x64.exe`：Windows x64 安装包。
- `TronCut-0.4.0-windows-x64.zip`：免安装版，完整解压后运行 `TronCut.exe`。
- `TronCut-0.4.0-macos-arm64.dmg`：Apple Silicon Mac 安装包。
- `TronCut-0.4.0-macos-x64.dmg`：Intel Mac 安装包。
- `SHA256SUMS.txt`：发布文件校验值。

安装包包含对应平台的 FFmpeg 与 uv，Windows 包还包含原生录屏组件，无需单独安装。首次使用语音功能需要联网准备 Python、依赖与模型。当前 Windows 与 macOS 包未配置代码签名，Mac 包未公证，也未完成安装、权限、录制和导出真机验收。项目源码直接以 GitHub 版本标签提供，不再额外附带 TronCut 源码 ZIP。完整 TREC 导入仍未提供。
