本版新增钢笔工具、全局画布运镜、可调整整体高度的时间轴，以及按住 Shift 自由调整素材宽高，完善录屏、字幕层级和项目启动。

## 更新内容

- **钢笔绘制**：在“标注 → 形状”中选择钢笔，点击添加顶点，拖动创建曲线手柄。点击起点闭合、双击、按 Enter 或点击“完成形状”即可生成形状，按 Esc 取消。
- **锚点与手柄编辑**：支持移动锚点、调整曲线手柄、按 Alt 独立调整手柄、沿路径插入和删除顶点，以及绘制过程中的撤销重做。选中已有钢笔形状后，再次启用钢笔即可继续编辑。
- **形状样式与变换**：支持填充、描边、笔宽、移动、缩放和旋转；顶点与手柄随项目保存，支持撤销重做、保存重开和截帧导出。
- **全局画布运镜**：缩放与平移统一作用于整个画布，沿用动画编辑交互，按需显示镜头轨道。
- **时间轴布局**：拖动上边缘调整整个时间轴高度，自动记忆，双击恢复默认；支持拖动轨道排序，录屏内部图层作为整体保持层级。
- **Shift 自由拉伸**：图片、视频、形状和草图运动按住 Shift 拖动缩放手柄即可分别调整宽高，例如把正方形拉成矩形；松开后继续使用原比例锁设置。
- **裁边与绘制**：修复跨轨道边缘吸附被隐藏录屏图层干扰的问题；裁短涂鸦时同步调整绘制过程。
- **字幕层级**：已有字幕轨道时，录制和拖放新增媒体轨道默认放在最后一条字幕轨道下方，保留原有轨道顺序和指定落点。
- **录屏改进**：记忆录制来源，默认启用原生录制并精简选项；修复录屏换轨、帧定格、背景时段以及整体缩放时的预览边界。
- **项目启动**：从资源管理器打开项目文件时直接进入指定项目，加载期间不再闪现首页或读取最近项目的画面。

完整改动见[更新日志](https://github.com/Achuan-2/TronCut/blob/v0.6.3/CHANGELOG.md)。

## 发布方式

本次发布仅更新源码、完成版本提交并创建 `v0.6.3` Git 标签，不依赖 GitHub Actions，不自动构建或上传安装包。

需要安装包时，可按[构建与发布说明](https://github.com/Achuan-2/TronCut/blob/v0.6.3/docs/BUILDING.md)在 Windows 执行 `pnpm dist:win`，或在 Mac 执行 `pnpm dist:mac`。

本轮功能已完成对应构建、核心测试和桌面专项验证；这些结果不代表新安装包或 Mac 真机验收。
