# TronCut v0.2.0 — 首个公开预发布 / First public preview

TronCut 将录屏、剪辑、文字、字幕和声音处理放在一个本地桌面工作区。本次提供 **Windows x64** 安装包与免安装版，源码采用 **AGPL-3.0-only**。

TronCut combines recording, editing, text, captions, and audio processing in a local desktop workspace. This preview provides **Windows x64** installer and portable builds. Original source is licensed under **AGPL-3.0-only**.

## 亮点 / Highlights

- Windows 原生录屏与独立鼠标轨迹：修改形状、大小、颜色、平滑移动与点击高亮。
- 时间线旁添加文本，黑边白字/白边黑字/黑边黄字模板，字幕自由定位。
- 右键与点击添加动画，位置/缩放/透明度自动关键帧。
- 多轨、多选、组合、同步移动、波纹删除、裁切旋转和画面效果。
- SenseVoiceSmall 本地字幕、Rubber Band 保调变速、DSP 播客声音与处理后试听。
- 可读 JSON 项目、素材与鼠标数据归档、相对路径、Windows 文件夹图标与素材重链接。

Editable cursors after native Windows recording; quick text and outlined presets; freely positioned captions; context-menu animations and auto keyframes; multitrack and grouped editing; crop, rotation, and effects; local SenseVoice captions, pitch-preserving speed changes, and DSP audio; portable JSON projects with collected media and relinking.

## 验证与限制 / Validation and limitations

类型检查、构建及 32 项核心测试通过；9 项 Python 测试和官方中文短样本 SenseVoice CPU 转录已通过。实际打包程序的录屏、暂停恢复、文本、动画、鼠标样式、保存与 MP4 导出已验证。

**Camtasia 导入仍不完整。** 实际项目测试仅导入音乐，3 段 TREC 与水波背景被跳过。尚未提供 Mac 安装包；Mac 真机、长录屏、4K/大型项目、多设备同步、完整效果库、TREC 元数据、GPU 合成和 GIF/音频/交互输出仍待开发或验收。本版不是完整 Camtasia 替代品。

Typecheck, build, and 32 core tests passed. Nine Python tests and actual SenseVoice CPU transcription of an official Mandarin sample passed. Packaged recording, pause/resume, text, animation, cursor styling, saving, and MP4 export were exercised.

**Camtasia import is incomplete:** a real project imported only the music and skipped three TREC recordings and a water-ripple background. No Mac artifact is available. Mac testing, long sessions, 4K/large projects, device synchronization, complete effects, TREC metadata, GPU compositing, and GIF/audio/interactive output remain unfinished or unverified. This is not a complete Camtasia replacement.
