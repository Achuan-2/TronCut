# 视频导出

点击右上角“导出”或按 Ctrl/⌘ + E，先打开导出设置窗口，确认后点击“开始导出”。导出过程中显示进度，可以取消任务；取消或失败会保留已有文件。

“导出位置”默认使用当前项目文件所在文件夹。尚未保存项目时，默认使用系统“视频”文件夹；可直接输入路径或点击“浏览…”更换目录。文件名默认使用项目名称，扩展名随所选格式生成。已有同名文件时会询问是否替换，禁止覆盖项目文件和源素材。

分辨率支持原画布、4K、2K、1080p、720p 和 480p，每项会显示实际输出宽高。横屏、竖屏及非标准画布保持比例，必要时补边至编码所需的偶数尺寸；项目画布、片段位置和字幕字号不变。帧率沿用项目帧率。

质量提供“高质量”“标准”“小体积”，依次侧重细节、平衡与压缩。格式支持 MP4、MOV、MKV 和 WebM：前三种使用 H.264 / AAC，WebM 使用 VP9 / Opus。MP4、MOV、MKV 优先尝试可用硬件编码器，失败后以相同质量档位回退到软件编码；WebM 使用软件编码。

成功导出后，分辨率、质量和格式会记在当前项目中，保存项目后可在重开时恢复。下次打开导出窗口，默认目录仍使用项目所在文件夹；取消设置或导出失败不会改变项目的导出偏好。

录屏导出会自动选择适合当前效果的处理路径：鼠标和自动缩放尽量保持 YUV 像素格式，静态圆角蒙版只生成一次；包含透明度动画、旋转或动态裁剪的片段使用通用合成路径。源素材、鼠标轨迹和时间线关键帧保持可编辑。非循环视频与音频直接从裁剪后的源时间开始解码，避免先处理已剪掉的部分。

开发者可运行 `pnpm bench:export --seconds=4 --rounds=2 --encoder=software --timeout=300000`，使用同一素材对比优化前后的实际导出耗时，报告及输出视频位于 `test-output/export-benchmark/`。默认对照提交为 `f8ee87d`，可用 `--baseline=<commit>` 指定；脚本只替换对照版本的 `electron/export.ts`，其余依赖与优化版一致。基准包含鼠标、自动缩放、背景和音轨，并对解码后的全部视频帧计算 SSIM；超时会记录失败，不能作为已完成导出的耗时。具体测试条件见[验证记录](VALIDATION.md)。
