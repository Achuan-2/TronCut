# 视频导出

点击右上角“导出”或按 Ctrl/⌘ + E，先打开导出设置窗口，确认后点击“开始导出”。导出过程中显示进度，可以取消任务；取消或失败会保留已有文件。

“导出位置”默认使用当前工程文件所在文件夹。尚未保存工程时，默认使用系统“视频”文件夹；可直接输入路径或点击“浏览…”更换目录。文件名默认使用工程名称，扩展名随所选格式生成。已有同名文件时会询问是否替换，禁止覆盖工程文件和源素材。

分辨率支持原画布、4K、2K、1080p、720p 和 480p，每项会显示实际输出宽高。横屏、竖屏及非标准画布保持比例，必要时补边至编码所需的偶数尺寸；项目画布、片段位置和字幕字号不变。帧率沿用工程帧率。

质量提供“高质量”“标准”“小体积”，依次侧重细节、平衡与压缩。格式支持 MP4、MOV、MKV 和 WebM：前三种使用 H.264 / AAC，WebM 使用 VP9 / Opus。MP4、MOV、MKV 优先尝试可用硬件编码器，失败后以相同质量档位回退到软件编码；WebM 使用软件编码。

成功导出后，分辨率、质量和格式会记在当前工程中，保存工程后可在重开时恢复。下次打开导出窗口，默认目录仍使用工程所在文件夹；取消设置或导出失败不会改变工程的导出偏好。
