# 文本与标注

## 添加与编辑

左侧“标注”统一提供“文本”“形状”“箭头”三类，文本类可筛选基本样式与花字。点击模板可在当前播放头处添加，也可拖到画布指定位置，或拖到时间线指定时间与轨道。新标注优先使用可编辑且不重叠的顶层轨道；目标轨道已占用或不可编辑时新建顶部轨道。

时间线旁的“添加文本”按钮继续创建文本片段。双击画布中的文字或时间线文本片段可直接编辑，Enter 换行，Esc 或 Ctrl/⌘ + Enter 结束编辑。文字内容与属性面板同步。花字模板预览仍统一显示“花字”。

形状包括圆角矩形、椭圆和箭头，选中后可在画布中拖动和等比缩放，画面属性可调整填充颜色、位置、尺寸、旋转和透明度。文字保留独立文本属性页、描边与自动字号；标注都可添加动画并随工程保存和视频导出。

分类与拖入交互参考：[Camtasia 文字标识与注释工具](https://www.luping.net.cn/bianji/cam-wzbs.html)。

## 独立文本属性页

文字样式位于属性面板的“文本”标签页，包括文字内容、花字、字号、文字颜色、描边颜色、描边宽度和字体。“画面”标签页用于位置、缩放、不透明度、旋转、宽高和翻转，不再提供“片段”标签页。开始位置和时长通过时间线移动、裁切调整，动画起止显示在时间线上。

## 文本框与自动字号

选中文本后，可拖动画布上的八个手柄调整文本框宽高。开启“自动调整文本大小”后，字号随框的尺寸自动适配；多行文字会同时考虑宽度和高度，修改文字内容时也会重新适配。此时字号框显示计算结果；需要手动设置字号时，关闭自动调整。

关闭后调整文本框尺寸会保留字号，旧工程默认关闭。文本框尺寸、开关状态和实际字号随工程保存，导出使用调整后的字号。锁定文本所在轨道后，文字编辑和尺寸调整会被禁用。

选中动画起点或终点时，文本的画布尺寸调整会记录为该关键帧的图层缩放，保留其他关键帧和整段文本的基础字号。退出关键帧编辑后，恢复文本框宽高及自动字号的普通调整方式。
