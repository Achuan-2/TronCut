# 文本与标注

## 添加与编辑

左侧“标注”提供“文本”“形状”“箭头”“模糊和高亮”“草图运动”“涂鸦笔”六类，文本类可筛选基本样式与花字。点击模板可在当前播放头处添加，也可拖到画布指定位置，或拖到时间线指定时间与轨道。新标注优先使用可编辑且不重叠的顶层轨道；目标轨道已占用或不可编辑时新建顶部轨道。

时间线旁的“添加文本”按钮继续创建文本片段。双击画布中的文字或时间线文本片段可直接编辑，Enter 换行，Esc 或 Ctrl/⌘ + Enter 结束编辑。文字内容与属性面板同步。花字模板预览仍统一显示“花字”。

形状包括椭圆、五角星、圆角矩形、矩形、黑白描边矩形、八边形和三角形。箭头提供直线、单向/双向箭头、点线/虚线箭头、圆点端点和实心箭头，属性中可调整填充、描边颜色、笔宽、线型及端点。选中后可在画布中移动和缩放，调整位置、尺寸、旋转与透明度，随项目保存和视频导出。

“模糊和高亮”提供模糊、聚光灯、突出显示和像素化，处理下方已合成的画面。区域支持矩形和椭圆，可调整强度、像素大小、背景暗度或高亮颜色与不透明度。

“草图运动”提供手绘圆、矩形、箭头、勾选、直线、叉号、五角星等十种模板，按笔迹顺序逐步绘制。“涂鸦笔”可设置颜色、笔宽和绘制时长，开启后直接在画布拖动，每一笔都是独立的可编辑时间线对象；也可从画布工具栏开启，Esc 退出。草图与涂鸦的“播放绘制过程”、时长和延迟可在属性中修改，并支持预览、拆分、变速、截帧和视频导出。

分类与拖入交互参考：[Camtasia 文字标识与注释工具](https://www.luping.net.cn/bianji/cam-wzbs.html)。

## 独立文本属性页

文字样式位于属性面板的“文本”标签页，包括文字内容、花字、字号、文字颜色、描边颜色、描边宽度和字体。“画面”标签页用于位置、缩放、不透明度、旋转、宽高和翻转，不再提供“片段”标签页。开始位置和时长通过时间线移动、裁切调整，动画起止显示在时间线上。

“背景色”开关可快速关闭或开启文字填充，关闭时保留颜色、不透明度、内边距和圆角，再次开启可恢复。新建字幕默认 40 号字、描边宽度 7、背景关闭；普通文本仍默认黑色背景、75% 不透明度。字幕轨道中的背景开关与其他样式一样统一作用于整轨字幕。

## 数学公式

文本和字幕支持 Markdown 风格公式：`$E=mc^2$` 为行内公式，`$$\frac{a}{b}=\sqrt{x}$$` 为独立一行的公式，双美元符号之间可以换行。支持分式、根号、上下标、求和、积分及矩阵等常见 LaTeX 写法。双击画布文字或在“文本内容”中编辑原始语法，结束画布编辑后显示公式；未闭合或错误语法保留为普通文字。

公式沿用“文字颜色”、字号和描边。选中公式源码后修改文字颜色，可单独设置该公式的颜色；也可使用 `$\textcolor{red}{x}+y$` 对公式内部着色。公式在预览、截帧、保存重开及视频导出中共用同一份图形，不需要联网或安装 LaTeX。逐字行为将一条公式作为一个整体处理。

## 文本框与自动字号

选中文本后，可拖动画布上的八个手柄调整文本框宽高。开启“自动调整文本大小”后，字号随框的尺寸自动适配；多行文字会同时考虑宽度和高度，修改文字内容时也会重新适配。此时字号框显示计算结果；需要手动设置字号时，关闭自动调整。

关闭后调整文本框尺寸会保留字号，旧项目默认关闭。文本框尺寸、开关状态和实际字号随项目保存，导出使用调整后的字号。锁定文本所在轨道后，文字编辑和尺寸调整会被禁用。

选中动画起点或终点时，文本的画布尺寸调整会记录为该关键帧的图层缩放，保留其他关键帧和整段文本的基础字号。退出关键帧编辑后，恢复文本框宽高及自动字号的普通调整方式。
