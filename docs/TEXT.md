# 文本

## 添加与编辑

点击时间线旁的“添加文本”创建文本片段。双击画布中的文字或时间线文本片段可直接编辑，Enter 换行，Esc 或 Ctrl/⌘ + Enter 结束编辑。文字内容与属性面板同步。

## 独立文本属性页

文字样式位于属性面板的“文本”标签页，包括文字内容、花字、字号、文字颜色、描边颜色、描边宽度和字体。“画面”标签页用于位置、缩放、不透明度、旋转、宽高和翻转，开始时间与时长位于“片段”标签页。动画起止显示在时间线上。

## 文本框与自动字号

选中文本后，可拖动画布上的八个手柄调整文本框宽高。开启“自动调整文本大小”后，字号随框的尺寸自动适配；多行文字会同时考虑宽度和高度，修改文字内容时也会重新适配。此时字号框显示计算结果；需要手动设置字号时，关闭自动调整。

关闭后调整文本框尺寸会保留字号，旧工程默认关闭。文本框尺寸、开关状态和实际字号随工程保存，导出使用调整后的字号。锁定文本所在轨道后，文字编辑和尺寸调整会被禁用。
