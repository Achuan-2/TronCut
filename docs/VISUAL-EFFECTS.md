# 视觉效果

左侧“视觉效果”支持拖到画布对象或时间轴片段，也可以双击应用到选中对象。拖动悬停时，兼容的画布对象显示呼吸高亮；锁定轨道拒绝附加效果。效果可叠加，在右侧属性面板调整、开关、重置或移除，操作支持撤销并随工程保存。画布预览、截帧与视频导出均支持这些效果。

## 媒体哑光与遮罩

“媒体哑光”将当前对象作为哑光源，控制所有下方轨道的可见区域。透明度模式在哑光源不透明的区域显示下层画面；透明度反转显示其余区域。亮度模式根据哑光源的明暗调整下层可见程度，亮度反转与之相反。可调整强度、缓入和缓出，支持图片、视频、文字与形状作为哑光源；哑光源本身不作为普通图层显示。该组合语义参考 [TechSmith 的媒体哑光说明](https://www.techsmith.com/blog/wp-content/uploads/2023/12/Camtasia-Help-2022-EN.pdf)。

“遮罩”支持椭圆或圆角矩形，可颠倒可见区域、旋转，调整位置、大小、遮挡区域不透明度与混合。选中对象后，可以直接拖动画布上的虚线区域移动遮罩，拖动右下角调整大小。负混合值向内柔化边缘，正值向外柔化。

## 阴影、移除颜色、着色、模糊区域与边框

| 效果 | 可调整内容 |
| --- | --- |
| 阴影 | 九宫格方向、角度、颜色、偏移、不透明度和模糊 |
| 移除颜色 | 指定移除的颜色、容差、柔和度、色彩抑制、去边及颠倒；用于绿幕等单色背景 |
| 着色 | 颜色、强度及范围，可作用于全部灰色、阴影、中间调或高光 |
| 模糊区域 | 局部模糊强度、覆盖色调及不透明度、形状、位置、大小、旋转、颠倒、圆角与羽化；支持在画布移动和缩放区域 |
| 边框 | 颜色、粗细；“使用透明度”沿对象的透明轮廓描边，关闭时使用对象的矩形边界 |

上述效果也支持缓入、缓出。剪切会保留原有效果的时间进度，变速时效果的缓入缓出时间同比缩放。关闭效果时参数保留，移除效果可通过撤销恢复。

## 圆角倒角

图片与视频支持按四角独立设置圆角，半径以百分比调整；100% 对应画面短边的一半。

## 剪辑速度

将“剪辑速度”拖到画布的视频对象，或时间线的视频、音频片段上；也可先选择片段，再双击效果卡片或点击“应用到所选片段”。多选时应用到所有未锁定的视频、音频，文字与图片不添加此效果。

添加后默认保持 1 倍速。片段底部的小三角可展开或收起效果条，效果显示在片段边框内部的底部区域；展开时片段和轨道高度一起增加，左侧轨道栏保持对齐。点击效果条后显示黄色，拖动右侧末端：向左缩短时长并加快播放，向右拉长时长并减慢播放。拖动按工程帧率对齐，支持撤销；普通片段边缘仍用于截取源区间，不会改变倍速。

选中带有该效果的片段，属性面板会显示“剪辑速度”。“速度”输入支持 0.25～8 倍，持续时间随之变化；也可输入分钟、秒、帧，反算对应速度。速度改变后，片段开始位置和所用源素材区间保持不变，动画关键帧、裁剪动画、动画偏移及淡入淡出时间同比缩放。其他片段不随之移动。

“恢复正常速度”恢复为 1 倍，效果仍保留；“移除剪辑速度”恢复 1 倍并移除效果。若之前截短过片段，恢复的是当前保留的源区间长度，不会恢复已剪掉的画面。效果与倍率随工程保存，拆分、复制时保留；旧工程已有倍速也会显示效果入口。

画布播放和视频导出均应用同一倍速，音视频同步变速并保持音调。导出优先使用 Rubber Band，缺少该滤镜时使用 FFmpeg atempo。
