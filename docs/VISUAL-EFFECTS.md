# 视觉效果

左侧“视觉效果”支持拖到画布对象或时间轴片段，也可以双击应用到选中对象。拖动悬停时，兼容的画布对象显示呼吸高亮；锁定轨道拒绝附加效果。效果可叠加，在右侧属性面板调整、开关、重置或移除，操作支持撤销并随项目保存。画布预览、截帧与视频导出均支持这些效果。

悬停效果卡片可循环预览对应效果，移开后恢复静态缩略图；键盘聚焦卡片也可预览，收藏夹中的效果卡片保持相同操作。预览使用本地示意画面，不修改当前项目；拖动时停止预览。系统开启减少动态效果时显示静态缩略图。

## 效果生效时间

遮罩、圆角倒角、媒体遮罩、阴影、移除颜色、着色、模糊区域和边框都有独立的时间条。点击片段底部的小三角可展开或收起，展开后效果条位于片段内部，轨道高度和左侧轨道栏同步增加。新增效果时自动展开；点击效果条会以黄色标记选中。

选中效果条后，按 Delete 只移除该效果，素材和其他效果保留；也可右键选择“移除效果”或“复制效果”。复制后，右键时间线素材或画布对象选择“粘贴效果”，也支持 Ctrl+C、Ctrl+X 和 Ctrl+V（macOS 使用 Command）。这些操作同样适用于剪辑速度，支持撤销、重做和保存重开；锁定轨道可复制效果，不可移除或粘贴。

粘贴保留效果参数，并按目标素材时长同比调整生效范围及缓入缓出；已有同类型效果会被替换，其他效果保留。复制遮罩时使用当前播放头处的遮罩参数，不附带素材运动或遮罩关键帧；圆角倒角仅支持图片和视频，剪辑速度仅支持音视频。

拖动效果条的左右端点设置开始和结束时间，拖动中间可整体移动，生效范围限定在当前片段内并按项目帧率对齐。聚焦端点后可用左右方向键逐帧调整，Shift 加方向键调整十帧；聚焦整条时方向键移动整个区间。Escape 或取消拖动恢复原范围，一次完成的拖动可单步撤销，锁定轨道不可调整。

调整效果条只改变效果的生效时间，素材时长和遮罩关键帧保留。效果范围外显示原画面，媒体遮罩范围外恢复普通图层。缓入缓出从效果条的起止时间计算；剪切保留原有效果进度，变速时范围同比缩放。时间范围随项目保存，并用于画布播放、截帧和视频导出。

## 媒体遮罩与遮罩

“媒体遮罩”将当前对象作为哑光源，控制所有下方轨道的可见区域。透明度模式在哑光源不透明的区域显示下层画面；透明度反转显示其余区域。亮度模式根据哑光源的明暗调整下层可见程度，亮度反转与之相反。可调整强度、缓入和缓出，支持图片、视频、文字与形状作为哑光源；哑光源本身不作为普通图层显示。该组合语义参考 [TechSmith 的媒体遮罩说明](https://www.techsmith.com/blog/wp-content/uploads/2023/12/Camtasia-Help-2022-EN.pdf)。

“遮罩”支持椭圆或圆角矩形，可颠倒可见区域、旋转，调整位置、大小、遮挡区域不透明度与混合。单击画布上的遮罩区域、虚线边框或“遮罩”标签，即可显示中央移动控制点；点击右侧遮罩属性、时间轴遮罩条或遮罩缩放点也能选中遮罩。拖动中央控制点调整遮罩位置，直接拖动其他画面区域（包括虚线边框）则移动整个素材，同时隐藏中央控制点。负混合值向内柔化边缘，正值向外柔化。

遮罩有四角和四边共八个控制点。拖动边缘或角点时，对侧边界固定，可单独扩大可见区域。位置、宽高、旋转、不透明度、混合与圆角都支持关键帧动画，素材的位置和大小保持独立。

制作从左向右展开的效果时，先选择矩形遮罩，把区域缩窄到素材左侧，再把播放头移动到动画结束时刻，开启“自动动画”，拖动遮罩右侧控制点向右展开。默认动画发生在播放头之前的一秒；可拖动时间轴动画箭头的两端调整起止时间，点击起点或终点后单独修改遮罩参数，也可以设置缓动、复制或删除这段动画。画布播放、截帧和视频导出均保留该滑动显示过程。

## 阴影、移除颜色、着色、模糊区域与边框

| 效果 | 可调整内容 |
| --- | --- |
| 阴影 | 九宫格方向、角度、颜色、偏移、不透明度和模糊 |
| 移除颜色 | 指定移除的颜色、容差、柔和度、色彩抑制、去边及颠倒；用于绿幕等单色背景 |
| 着色 | 颜色、强度及范围，可作用于全部灰色、阴影、中间调或高光 |
| 模糊区域 | 局部模糊强度、覆盖色调及不透明度、形状、位置、大小、旋转、颠倒、圆角与羽化；支持在画布移动和缩放区域 |
| 边框 | 颜色、粗细；“使用透明度”沿对象的透明轮廓描边，关闭时使用对象的矩形边界 |

上述效果也支持缓入、缓出。剪切会保留原有效果的时间进度，变速时效果的缓入缓出时间同比缩放。关闭效果时参数保留，移除效果可通过撤销恢复。

## 圆角倒角

图片与视频支持按四角独立设置圆角，半径以百分比调整；100% 对应画面短边的一半。

## 剪辑速度

将“剪辑速度”拖到画布的视频对象，或时间线的视频、音频片段上；也可先选择片段，再双击效果卡片或点击“应用到所选片段”。多选时应用到所有未锁定的视频、音频，文字与图片不添加此效果。

也可右键视频或音频，选择“添加剪辑速度”，直接添加效果并保留当前倍率，再在属性面板中调整速度或持续时间。多选时一起添加到所选音视频；已有剪辑速度效果的片段不重复添加，锁定选区不可使用该菜单项。

添加后默认保持 1 倍速。片段底部的小三角可展开或收起效果条，效果显示在片段边框内部的底部区域；展开时片段和轨道高度一起增加，左侧轨道栏保持对齐。点击效果条后显示黄色，拖动右侧末端：向左缩短时长并加快播放，向右拉长时长并减慢播放。拖动按项目帧率对齐，支持撤销；普通片段边缘仍用于截取源区间，不会改变倍速。

选中带有该效果的片段，属性面板会显示“剪辑速度”。“速度”输入支持 0.25～8 倍，持续时间随之变化；也可输入分钟、秒、帧，反算对应速度。速度改变后，片段开始位置和所用源素材区间保持不变，动画关键帧、裁剪动画、动画偏移及淡入淡出时间同比缩放。其他片段不随之移动。

“恢复正常速度”恢复为 1 倍，效果仍保留；“移除剪辑速度”恢复 1 倍并移除效果。若之前截短过片段，恢复的是当前保留的源区间长度，不会恢复已剪掉的画面。效果与倍率随项目保存，拆分、复制时保留；旧项目已有倍速也会显示效果入口。

画布播放和视频导出均应用同一倍速，音视频同步变速并保持音调。导出优先使用 Rubber Band，缺少该滤镜时使用 FFmpeg atempo。
