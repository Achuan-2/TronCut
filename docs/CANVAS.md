# 画布与动画

## 顶部画布工具

画布预览顶部提供“选择”和“裁剪”模式。选择模式可移动素材、等比调整图片和视频尺寸，以及双击编辑文本；裁剪模式选中图片或视频后，拖动八个方形手柄可裁剪对应边缘，向外拖动可恢复部分区域，“恢复裁剪”可还原完整素材和框内变换。边缘裁剪保持保留区域的像素比例和对侧位置，支持旋转、水平/垂直翻转以及撤销；锁定轨道的素材不可裁剪。

裁剪模式下，拖动图片或视频本身会移动框内画面，属性中的缩放滑条与数值输入也只缩放框内内容，外框的位置和尺寸保持不变。可用“内容位置 X/Y”精确平移，“内容居中”重置内部位置；裁剪框宽高只读。超出外框的内容隐藏，缩小或移出素材后露出下方背景，适合背景加视频的固定窗口布局。切回选择模式后，缩放与位置恢复为整个外框的变换，已经调整的内部内容仍保留。

开启“自动动画”后，框内缩放、平移和裁剪边缘操作会生成以当前播放头为终点、默认持续 1 秒的动画箭头；同一时间继续调整更新已有终点，两段动画之间保留静止区间。只动画缩放和平移时，外框始终固定，可制作固定窗口里的画面放大、移动；动画裁剪边缘时，裁剪范围随时间变化并保持对侧锚点。

点击动画箭头起点或终点后，即使关闭自动动画，裁剪模式的缩放、平移、边缘调整及“恢复裁剪”也只修改该端点。起点沿用时间线规则：有前一段动画时修改前一个终点，否则修改初始状态，不额外新增箭头。修改终点时圆点播放放大动效。裁剪动画支持箭头拖动、缓动、复制、删除、分割、撤销、保存和视频导出；没有开启自动动画且未选择端点时，裁剪操作仍按静态修改处理。

复制其他片段的属性后，若已选中动画起点或终点（红点），再选中同一画布对象并右键“粘贴属性”，只将位置、缩放、旋转、透明度、裁剪和框内变换等可动画属性粘贴到该端点。打开画布或时间线右键菜单会保留当前端点选择，其他关键帧和整段的文字样式、音量及效果保持原值；未选中端点时仍按整段片段粘贴。

显示比例菜单提供“适合”及 25%、50%、75%、100%、200%、300%、800%、1200%、1600%、2000%。大于预览区域时可通过滚动条查看画布，切换显示比例时居中显示；“适合”随窗口大小自动调整。显示比例只影响编辑时的预览，不改变素材尺寸、动画或导出分辨率。

鼠标位于画布区域时，可按 Ctrl/⌘ + 加号或减号缩放，也支持 Ctrl/⌘ + 滚轮，以鼠标位置为缩放中心；键盘缩放以预览区域中心为基准，范围为 5%～2000%。显示比例菜单会同步显示当前百分比。文本和数值输入框编辑期间不响应缩放快捷键。

画布外围使用透明棋盘背景，图片、视频等素材移出画布的部分仍可显示、选中和拖动。画布边框标明实际输出区域，全屏预览和视频导出仍按画布边界显示。

点击顶部右侧的画布尺寸，或显示比例菜单中的“画布大小设置…”，可选择横屏、竖屏、方形、720p、4K 等预设，也可输入自定义宽度（16～7680 像素）、高度（16～4320 像素）、帧率（1～120 fps）并设置背景色。点击“应用”保存到工程并用于导出，支持撤销；取消或 Esc 关闭时不修改工程。

## 播放条

画布下方依次提供前一帧、后一帧、播放/暂停、前一个媒体、后一个媒体，并显示播放进度滑条、当前时间/总时长、项目帧率和全屏预览。逐帧操作按项目帧率定位到相邻帧；前后媒体按可见轨道的片段起止边界定位，跨轨道重合的边界只停一次。逐帧、媒体跳转和拖动进度都会暂停播放，空工程或开头/结尾处会禁用相应按钮。

左右方向键可逐帧移动，Ctrl/⌘ + 左右方向键跳转前后媒体。进度滑条获得焦点时，Home/End 可定位开头和结尾。播放到结尾后再次点击播放，会从开头重新播放。

点击播放条右侧“全屏预览”可全屏查看画布，自动适应屏幕并隐藏编辑手柄；播放条保留，可继续播放、逐帧及跳转媒体。点击“退出全屏预览”或按 Esc 返回编辑器，恢复进入全屏前的显示比例，不修改工程画布或素材属性。

## 图层尺寸与位置

选中画布中的图片或视频后，可拖动八个手柄调整尺寸，拖动图层本身可修改位置。画面属性页提供缩放、不透明度、旋转、位置、宽高以及水平翻转、垂直翻转。尺寸按画布像素显示，宽高之间的锁按钮默认锁定比例；点击解锁后，修改宽度或高度只影响对应方向，画布手柄也可独立拉伸。重新锁定后保持当前宽高比例，不会恢复原始比例。锁定状态和独立缩放随工程保存，支持撤销、自动动画、关键帧端点编辑和导出；裁剪模式下外框尺寸及比例锁只读。文本框宽高可独立调整，配合 [自动字号](TEXT.md#文本框与自动字号) 使用。

缩放支持 5%～800% 的滑条、数值输入和重置按钮（恢复到 100%），二者同步。旋转区按 Z、Y、X 顺序排列三行拨盘与角度输入：Z 控制平面旋转，X/Y 控制画面倾转，支持负角度及多圈旋转。拖动拨盘连续调角度，跨越一圈时保持连续；双击拨盘归零。拨盘聚焦时，方向键每次微调 1°，Shift + 方向键微调 10°，Home 归零。三轴旋转参与自动动画及箭头端点编辑，保存、复制动画和视频导出均保留。

属性面板不再提供“片段”页，开始位置和时长通过时间线移动、裁切调整。音频素材保留“声音”页，可调整音量和人声增强；播放速度通过 [视觉效果中的剪辑速度](VISUAL-EFFECTS.md) 设置。画面页不显示通用画面效果、裁切、淡入淡出和关键帧列表；动画起止可以直接在时间线上定位。

## 自动动画

开启“自动动画”后，修改图层位置、缩放、不透明度或旋转会创建以当前播放头为终点、默认持续 1 秒的动画；靠近片段开头或前一个动画时，时长会缩短以避免越界和重叠。同一时间继续调整会更新已有终点。图片、视频的画布拖动和等比缩放也使用此方式，两段动画之间保持静止，不自动连接箭头。

点击时间线动画箭头的起点或终点后，可直接编辑该关键帧，关闭“自动动画”也能使用。属性面板显示当前编辑的是起点还是终点；画布拖动与尺寸调整也只作用于该帧。手动移动播放头、开始播放、选择其他片段或点击“退出”后恢复普通编辑。

编辑中的圆点会放大，退出后恢复。点击动画起点时，如果前面有动画，会编辑前一个动画的终点，并同步两段之间的静止状态；如果没有前一个动画，则编辑初始属性，不会在片段开头额外生成一段动画。

动画面板只提供“自定义动画”，点击后与时间线的“添加动画”按钮一致。将卡片拖到时间轴片段的指定位置，会以落点为动画终点，并预览插入范围；拖到画布对象时，在当前播放头处添加，画布空白区域则作用于当前选中的对象。添加后可编辑终点属性、拖动箭头调整起止位置；右键动画箭头可剪切、复制、删除及选择缓动。时间线的起止显示与定位方式见 [动画起止箭头](TIMELINE.md#动画起止箭头)。

## 缩放与平移

“缩放与平移”面板为当前播放头处所有可见、未锁定的视频同步添加动画。拖动取景框可平移，调整取景框尺寸或缩放百分比可缩放，默认动画持续 1 秒、结束于当前时间。取景变换保留视频间的相对布局；同一时间继续调整会更新已有终点，不会累计放大。动画箭头显示在各视频片段内，可拖动、编辑和选择缓动，保存工程和导出视频时保留这些动画。

面板保留取景预览、全画面、清除运镜和缩放，移除取景中心 X/Y、运镜关键帧标题、添加按钮及列表，刻度尺不显示运镜关键帧。“全画面”在当前时间添加还原取景的动画；“清除运镜”清除未锁定视频的取景变换。没有可编辑视频时，缩放控制禁用。旧工程的整幅画面运镜仍可读取播放，清除运镜也会移除旧设置。
