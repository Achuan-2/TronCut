# 画布与动画

## 图层尺寸与位置

选中画布中的图片或视频后，可拖动八个手柄等比调整尺寸，拖动图层本身可修改位置。画面属性页提供缩放、不透明度、旋转、位置、宽高以及水平翻转、垂直翻转。图片和视频修改宽度或高度时保持比例，尺寸按画布像素显示；文本框宽高可独立调整，配合 [自动字号](TEXT.md#文本框与自动字号) 使用。

片段开始时间、时长、播放速度和声音设置位于独立的“片段”页。画面页不显示画面效果、裁切、淡入淡出和关键帧列表；动画起止可以直接在时间线上定位。

## 自动动画

开启“自动动画”后，修改图层位置、缩放、不透明度或旋转会创建以当前播放头为终点、默认持续 1 秒的动画；靠近片段开头或前一个动画时，时长会缩短以避免越界和重叠。同一时间继续调整会更新已有终点。图片、视频的画布拖动和等比缩放也使用此方式，两段动画之间保持静止，不自动连接箭头。

点击时间线动画箭头的起点或终点后，可直接编辑该关键帧，关闭“自动动画”也能使用。属性面板显示当前编辑的是起点还是终点；画布拖动与尺寸调整也只作用于该帧。手动移动播放头、开始播放、选择其他片段或点击“退出”后恢复普通编辑。

编辑中的圆点会放大，退出后恢复。点击动画起点时，如果前面有动画，会编辑前一个动画的终点，并同步两段之间的静止状态；如果没有前一个动画，则编辑初始属性，不会在片段开头额外生成一段动画。

动画面板提供淡入、缩放、滑入等动画预设。素材右键菜单已移除这些预设；右键动画箭头可剪切、复制、删除及选择缓动。时间线的起止显示与定位方式见 [动画起止箭头](TIMELINE.md#动画起止箭头)。

## 缩放与平移

“缩放与平移”面板针对整个画面调整取景，作用于合成后的所有图层。拖动取景框可平移，调整取景框尺寸或缩放百分比可缩放，并自动生成运镜关键帧。保存工程和导出视频时保留这些动画。

“全画面”将当前时间的取景恢复为完整画面；“清除运镜”移除整幅画面的运镜设置。面板中的关键帧列表可定位、添加和删除关键帧。
