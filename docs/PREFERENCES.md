# 编辑菜单与首选项

顶部“编辑”菜单在首页和编辑器中均可打开，“首选项…”位于菜单末尾，也可以按 Ctrl/⌘ + 逗号打开。

## 编辑命令

| 命令 | 快捷键 |
| --- | --- |
| 撤销 / 重做 | Ctrl/⌘ + Z / Ctrl/⌘ + Shift + Z，Windows 也可用 Ctrl + Y 重做 |
| 剪切 / 复制 / 粘贴 | Ctrl/⌘ + X / C / V |
| 创建副本 | Ctrl/⌘ + D，在所选片段结束后添加副本 |
| 删除 / 波纹删除 | Delete / Shift + Delete |
| 在播放头处分割 | Ctrl/⌘ + K |
| 拼接所选媒体 | Ctrl/⌘ + Alt + I |
| 移除全部拼接 | Ctrl/⌘ + Shift + 反斜杠 |
| 组合 / 取消组合 | Ctrl/⌘ + G / Ctrl/⌘ + Shift + G |
| 全选 / 取消选择 | Ctrl/⌘ + A / Escape |

菜单按选择、轨道锁定和撤销历史启用对应命令。编辑文字或工程名称时，剪切、复制、粘贴、全选和撤销作用于当前输入框。选中动画或行为时，剪切、复制与删除作用于该效果；普通片段粘贴到播放头处。

## 分组首选项

| 分组 | 设置与生效范围 |
| --- | --- |
| 程序 | 默认工具、画布显示比例、时间线吸附、音频波形、自动恢复备份、备份文件夹及修改停止后的备份间隔。默认备份间隔为 2 秒，可设置为 1–600 秒。 |
| 计时 | 新增动画、图像、文字、注释、转换、手动字幕的默认持续时间，支持恢复默认值。导入字幕和语音识别字幕使用原始时间。 |
| 快捷键 | 查询和搜索当前支持的快捷键。 |
| 项目 | 默认项目创建位置，新项目画布宽高、帧率、背景，以及录屏鼠标样式、大小、平滑、点击高亮和自动聚焦缩放。 |
| AI 模型 | 以服务管理 API 地址和密钥，同一服务可添加多个模型，选择当前使用的模型。 |
| 高级 | ONNX 模型文件夹、打开应用配置文件夹。 |

点击“确定”保存全部分组，“取消”或关闭窗口放弃本次未保存修改。首选项保存在本机应用数据目录，不写入工程。新项目默认值不会改变已打开工程的画布；计时设置不会修改已有片段。自动恢复备份用于异常退出后恢复编辑，不代替手动保存。

三个存储位置均支持“选择文件夹”、恢复默认和打开当前文件夹，更改后点击“确定”生效。默认项目位置为系统“文档”目录下的 `TronCut/Projects`，仅用于后续新建或首次保存的工程，已有项目保留原位置。默认备份位于应用数据目录，默认模型位于其中的 `models/onnx`。切换备份或模型目录时，会复制已有文件并保留源文件，目标目录已有的同名文件优先使用；模型较大时需等待复制完成。切换模型目录需等待后台任务完成，字幕识别、配音、声音克隆、模型下载和 CLI 共用所选模型位置，Python 运行环境仍保存在应用数据目录。

录屏默认值与录制窗口共用配置，原来的录屏设置会自动迁移。修改这些默认值后，下次录制使用新值；已有录屏片段仍可在“视频”“鼠标”属性中单独编辑。

AI 服务支持获取模型列表、搜索、多选添加以及手动填写模型 ID，详见 [AI 模型与字幕处理](AI-CAPTIONS.md)。旧模型和密钥保留，密钥使用系统安全存储加密。
