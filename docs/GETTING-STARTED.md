# 开始使用

1. 点击“录制”选择屏幕或窗口，或点击“导入媒体”添加视频、音频和图片。
2. 双击素材加入时间线，用“添加文本”、动画和属性面板完善画面。
3. 保存工程，软件会收集素材到工程文件夹；点击“导出”生成 MP4。

也可打开 [纯文字视频示例](../examples/文字视频.framecraft)。TronCut 同时支持读取旧 `.framecraft` 工程，工程迁移方式见 [工程管理](PROJECTS.md)。

详细操作按 [素材与录屏鼠标](MEDIA.md)、[时间线](TIMELINE.md)、[文本](TEXT.md)、[画布与动画](CANVAS.md) 和 [本地配音](TTS.md) 分别说明。
