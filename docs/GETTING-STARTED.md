# 开始使用

启动 TronCut 默认进入首页，提供“新建录制”“新建项目”“打开项目”和最近项目。新建项目从空白时间线开始，直接存放在系统“文档”目录下的 `TronCut/Projects`，无需选择路径；点击最近项目可直接继续编辑。存在上次未保存的编辑时，首页显示“恢复编辑”，需要手动点击后才载入，启动时不会自动恢复。

1. 在首页点击“新建录制”选择屏幕或窗口，或点击“新建项目”后用“导入媒体”添加视频、音频和图片。
2. 双击素材加入时间线，用“添加文本”、动画和属性面板完善画面。
3. 保存项目，软件会收集素材到项目文件夹；点击“导出”生成 MP4。

可在“编辑 → 首选项 → 程序 → 存储”中自定义默认项目创建位置。需要单独指定某个项目的存放位置时，右键顶部项目名称或首页最近项目，选择“另存为…”。在最近项目的右键菜单中选择“打开项目位置”，可在文件管理器中定位项目。

也可打开 [纯文字视频示例](../examples/文字视频.framecraft)。TronCut 同时支持读取旧 `.framecraft` 项目，项目迁移方式见 [项目管理](PROJECTS.md)。

详细操作按 [素材与录屏鼠标](MEDIA.md)、[时间线](TIMELINE.md)、[文本](TEXT.md)、[画布与动画](CANVAS.md) 和 [本地配音](TTS.md) 分别说明。
