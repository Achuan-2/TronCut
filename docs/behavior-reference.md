# Camtasia 行为参考与验证

本轮使用用户提供的 `references/camtasia/文本行为动画照搬/行为.mp4`、配套的 `行为.tscproj/行为.tscproj`，以及文本和对象的“切换”录屏、六张属性截图作为参考。原参考文件只读，不参与运行时依赖。

## 参数与轨迹

`shared/behavior-reference.ts` 保存预设的三个阶段。阶段时长、字符偏移、循环时间、延迟和幅度从项目参数提取，时间按 `editRate = 705600000` 换算为秒。截图显示的 0.03 s 在原项目中是 1/30 s，内部保留完整精度。

| 预设 | 参考中的主要运动 | 本轮处理 |
| --- | --- | --- |
| 切换 | 文字上下交错，从中心向外错开；对象从上方进出 | 文本框裁切、弹簧回摆、期间小幅平移、正确方向的出场缓动 |
| 弹出 | 沿边缘翻起，期间轻微翻动 | 三维旋转与边缘枢轴位移，替代整体等比缩小 |
| 逐个显示 | 按字显示、淡入、滑入、飞入，搭配不同的期间和出场阶段 | 保留各预设的阶段组合；新增“结束散开（适合结尾）” |
| 飞入 | 大尺寸逐字向最终尺寸收敛，出场时反向远离 | 透视比例曲线、字间位置展开、高分辨率字形缓存 |
| 爆炸 | 字符沿不同方向离开并翻转 | 分散方向和独立的平面、纵轴旋转 |
| 缩放、脉动 | 逐字放大，脉动最大比例为 1.08 | 弹簧入场与独立出场，期间幅度以正常尺寸为下限 |
| 摆动、颤动 | 水平和竖直的小幅变化，颤动包含轻微旋转 | 确定性双轴轨迹，提供水平、垂直、频率、旋转调节 |
| 漂移、滑动、显示、淡入淡出 | 各自独立的进、期间、出参数 | 校正阶段组合、间隔、方向和透明度，移动效果不再统一渐变 |

参考项目没有包含 Camtasia 的内部曲线实现或随机种子。弹簧使用项目给出的阻尼和刚度构建；透视、散开与噪声轨迹依据录屏重建。字符排序中 6、7 的解释及部分移动枚举依照参考画面映射。这些属于实现选择，不能视为内部算法或每个像素完全一致；字体栅格化和随机运动仍可能与原片不同。未出现在参考视频中的旧“波浪”“跳起和下落”“逐字缩放”继续保留。

## 预览、导出与兼容

预览、视频导出和截帧使用一致的阶段边界、弹簧参数与运动通道。文字逐字翻转在字形纹理中完成，对象翻转交给整层三轴变换；逐字纹理不再重复经过整层三维采样滤镜。修改速度或张力会同步调整预设时长，其他参数、手动关键帧和内容变换继续独立保存。旧项目缺少新增参数时由 schema 补默认值。

## 重现检查

```powershell
pnpm exec vitest run tests/behavior-reference.test.ts tests/behaviors.test.ts tests/behaviors-export.test.ts tests/keyframe-edit.test.ts
pnpm run build
node scripts/smoke-behaviors.mjs
node scripts/smoke-behavior-reference.mjs
node scripts/compare-behaviors.mjs
```

`compare-behaviors.mjs` 根据原项目的 18 段片段建立可编辑 TronCut 项目，逐段实际导出，再生成左侧 Camtasia、右侧 TronCut 的并排视频。结果位于独立的 `test-output/behavior-comparison-*` 目录；对比图放大中央区域，便于检查小字运动。此脚本需要本地参考文件，普通构建与测试不需要。

`tests/frame-properties.test.ts` 的图片夹具已补齐素材引用，圆角校验与三轴旋转实际导出检查通过；新增百分比圆角同时验证静态裁切、动画裁切及旧像素圆角兼容。
