# 完整产品目标与当前交付边界

## 实施顺序

第一阶段交付本版的录制—剪辑—保存—导出闭环并修复基础问题。第二阶段以可编辑光标、原生捕获、真实字幕准确率、播客音频调校和 Mac 安装作为重点，优先解决用户列出的痛点。第三阶段补齐核心 NLE 功能：多选、波纹、组、裁切/旋转/遮罩、转场、波形、代理媒体和统一 GPU 渲染。第四阶段以真实 Camtasia 工程回归集推进完整兼容，再评估交互/SCORM、AI 和协作功能。

## 后续需要的真实样本

开发验收应覆盖：包含 TREC 与鼠标效果的录屏工程；多轨、字幕、动画、拼接与组的 Camtasia 工程；同一段原始旁白及 1.5×/2× 输出；具有背景噪声和混响的旁白；中文夹英文、快速说话与静音段的字幕素材；长时间 1080p/4K 录制。样本不应通过猜测 schema 替代，转换失败必须可追溯。
