# 时间线

## 通用轨道

轨道不区分文字、视频或音频类别，统一显示为“轨道1、轨道2……”，任何轨道都可以放置不同类型的片段。编号从底部开始，新增到顶部的轨道使用下一个编号。旧工程打开后统一使用编号，片段、动画及轨道的隐藏、静音和锁定状态保留。

粘贴新增图片或视频时，最顶层轨道完全没有片段且未锁定、未隐藏，就直接使用该轨道；否则在顶部新增轨道。素材放到当前播放头位置，已有片段保持原位。批量粘贴逐个判断，后续素材不会与本次已加入的素材叠在同一轨道；已有素材但播放头处空闲的轨道不算空轨道。

## 片段编辑

按住 Ctrl/⌘ 或 Shift 点击片段进行多选，也可以从时间线轨道空白处拖出矩形选区，一次选中相交的多个片段；按住 Ctrl/⌘ 或 Shift 框选会保留原选择。选中后可统一删除或拖动，锁定、隐藏轨道不参与框选。组合后的片段会一起选择与移动，复制粘贴保持相对位置。

右键片段选择“重命名”，输入素材名称后按 Enter 或点击“保存名称”。多选时仅修改右键点击的片段，锁定轨道上的片段不可重命名。名称随工程保存，支持撤销、重做；源文件、项目媒体名称及文字内容保持原样。组合继续使用“重命名组”，打开组后可单独重命名组内片段。

右键菜单底部集中显示帧定格、拆分视频和音频、拼接及在播放头拆分，拆分项不带独立图标。“粘贴效果”仅在已复制效果时显示，与“复制属性”“粘贴属性”放在同一分组。

视频片段连续显示对应时间的画面缩略图，图片片段平铺同一张预览，顶部显示名称与时长，下方保留音频波形。画面随裁剪、速度、拼接、帧定格和循环取样，定格与拼接接缝处分段显示。含视频或图片的轨道默认高度为 100 像素，手动调整的轨道高度优先；缩略图只加载可见区域及相邻画面，滚动后按需加载，缩放直接复用固定源时间网格上的预览帧；放大到更细一档后，等待缩放停稳再补充缺少的帧，期间先显示同一源区间的缓存画面。缩小或回到已加载档位不重复解码，图片始终复用同一张预览，离线素材不请求预览。

波纹删除会收拢选中片段所在轨道的后续片段，其他轨道上的标题、背景或配音不会阻止收拢，也不会跟随移动。所选轨道中仍有片段占用的时间会保留，避免剪掉未选中内容；多轨选区使用同一时间映射以保持同步，锁定轨道保持原位。滚动轨道时，顶部时间刻度尺保持可见。

时间线缩放滑杆按当前总时长和视窗宽度换算比例，最小档完整显示时间轴，后续各档按比例放大。长短工程使用同一套相对缩放范围，长工程也可以缩小到全览。

工具栏按钮、滑杆、Ctrl/⌘ + 加减号和 Ctrl/⌘ + 滚轮均围绕播放头缩放，播放头在视窗内时尽量保持屏幕位置；播放头不在视窗内时，缩放会将其带回视窗。普通滚轮继续滚动轨道。缩放只改变显示比例，不修改片段时间或轨道高度。

时间线最大可放大到 2400 像素/秒，便于查看和调整短动画。放大后标尺会逐步细化到帧，显示为“分:秒:帧”，帧数使用工程帧率计算。

点击删除图标直接删除选中片段；旁边的下拉箭头提供“删除”和“波纹删除”，工具栏不再单独显示波纹删除按钮。Delete 和 Shift + Delete 快捷键继续可用，删除支持撤销。

时间线工具栏不显示“组合”按钮，组合与解组仍可使用快捷键。点击“截取当前帧”会暂停播放，按工程画布分辨率生成当前时刻的 PNG 图片，并在顶部新增轨道，将图片放在当前播放头位置，默认时长 5 秒。截帧包含可见图层、文字、背景、鼠标及当前动画、裁剪效果，不包含编辑手柄和界面；不需要选择素材，也可截取空白背景。图片同时加入媒体库，保存工程时归档到工程素材文件夹，插入支持撤销。

## 组合编辑

主时间线上的组合可以整体拖到其他轨道，成员的相对时间和上下层次一同保留；目标轨道下方不足时自动补足内部轨道。锁定成员、锁定目标及轨道类型不兼容时不会部分移动，操作支持撤销、重做与保存重开。

双击组合或右键“打开组”，组内素材继续使用主时间线的绝对位置与刻度，并只显示当前组合成员。组合起点之前和终点之后整块置灰，不能定位、选范围或放入素材；播放头、范围手柄、播放进度和前后帧定位均限制在组合区间，播放到终点自动停止。编辑改变组合起止后，范围会随成员更新；返回“主时间线”可继续查看完整项目。

## 时间范围选择

播放头两侧提供绿色起点和红色终点手柄。拖动任一手柄即可选择一段时间，蓝色区域覆盖范围内的所有轨道；端点按工程帧率对齐，也可聚焦手柄后用方向键逐帧调整。双击中间的白色播放头按钮，或按 Esc，可收起范围。

起止手柄与播放头重合时显示为两侧的小矩形，分离后才显示尖角；两个端点分别判断。悬停播放头或起止手柄时保留原色并轻微提亮，鼠标保持普通箭头，仍可按住拖动。

选中范围后，Delete 裁开边界并删除范围内的内容，范围外片段保持时间位置；Shift + Delete 同时将可编辑轨道上的后续内容向前收拢，包含范围内原有空白，标记随之移动。锁定轨道及含锁定成员的组合保持原样。范围删除支持撤销、重做，完成后播放头回到范围起点。工具栏删除按钮及其下拉菜单也可作用于所选时间范围。

## 拆分视频和音频

在时间线上右键带声音的视频，选择“拆分视频和音频”，即可在下方新轨道生成同步的音频片段。新片段继续使用原始素材的音频流，保留裁剪、变速、拼接、音量和淡入淡出；视频的画面、动画与效果保留，视频片段本身不再发声。两者可以分别剪辑，保存重开、预览、字幕识别和导出均保留拆分状态，操作支持撤销、重做。

无声音、已拆分、离线的视频及锁定轨道不允许重复拆分。一次可选择多个视频；同一来源轨道中的多个视频共用一条新音轨，保留来源轨道的隐藏、静音和独奏状态。

## 帧定格

将播放头移到视频片段中的目标帧，右键选择“帧定格…”，输入持续时间并确定。定格区域保留在同一个视频片段中，以两条虚线接缝和斜纹标出；这段时间保持同一源帧并静音，结束后继续播放原视频，当前轨道的后续片段随时长变化顺延。

双击定格区域或右键选择“调整帧定格时长”，可重新输入秒数；拖动定格区域右边缘也可按帧调整时长。右键“移除帧定格”可恢复原视频。操作支持撤销、重做和保存重开，预览、视频导出、单帧截取及音频导出使用同一时间映射。锁定、离线或循环视频不能添加，组合视频需先打开组。

## 片段拼接

选中同一轨道、来自同一音视频素材且首尾相接的片段，右键选择“拼接所选媒体”，或按 Ctrl/⌘ + Alt + I。拼接后在时间线上显示为一个片段，可以统一移动、裁剪、变速、调整属性及添加跨片段动画，内部以虚线标出原来的拼接点。源素材中剪掉的内容不会恢复，保存工程时会保留拼接关系。

右键虚线拼接点，选择“移除拼接”可拆开这一处；右键片段选择“移除全部拼接”，或按 Ctrl/⌘ + Shift + 反斜杠，可按原拼接点全部拆开。Ctrl/⌘ + K 仍可在当前播放头处分割。拆开后保留源区间与整体动画的时间关系，操作支持撤销、重做。

拼接要求所选片段的速度、画面和声音属性兼容，内部接缝不能带独立转场或淡入淡出；不兼容时菜单禁用，悬停可查看原因。组合或录屏组合请先解组。跨轨道、多素材或属性不同的内容可以继续使用“组合”一起选择和移动。

## 点标记与区域标记

工具栏旗帜按钮在播放头处添加点标记；“区域标记”按钮以选中片段的整体起止范围创建标记，没有选中片段时默认从播放头开始、持续 1 秒。也可以按住 Shift 在标尺上拖出区域，正向、反向均可，Esc 取消本次框选。编辑窗口可填写名称、多行备注、起止时间，并选择八种预设颜色或自定义颜色；取消不会修改工程。

标尺下方以彩色条显示区域与名称，悬停可查看时间和完整备注。单击标记定位播放头，双击或右键打开编辑窗口；窗口内可修改、删除标记或切换点标记与区域标记。拖动彩色条整体移动，拖动两端调整范围，按工程帧率对齐，区域至少保留一帧。启用吸附时，标记可吸附到播放头、片段边缘及其他标记边缘，片段也可吸附到标记的起止位置。

标记或边缘获得键盘焦点后，左右方向键逐帧移动或调整边缘，Shift + 左右方向键每次调整 1 秒，Delete 仅删除该标记，Esc 取消拖动。每次拖动只产生一个撤销步骤。波纹删除同步映射区域的两端，完全被删去的区域收缩为点标记。名称、备注、颜色和范围随工程保存；旧工程的点标记保留原有黄色。标记可以超出片段末尾，不会延长视频导出时长。

实现位于 `shared/markers.ts`、`src/TimelineMarkers.tsx` 和 `src/MarkerDialog.tsx`。`markers` 保留旧字段 `id/time/label`，新增可选的 `duration/comments/color`；没有 `duration` 或时长为 0 时为点标记。运行 `pnpm exec vitest run tests/markers.test.ts tests/timeline.test.ts tests/editor.test.ts` 验证模型与编辑规则，构建后运行 `node scripts/smoke-markers.mjs` 验证桌面交互和保存重开。

## 动画起止箭头

“添加文本”右侧的“添加动画”按钮可为选中的图片、视频、文本或形状创建可编辑动画，支持多选；只有当前播放头所在且未锁定、未隐藏的对象会添加。默认持续 1 秒，以当前播放头为终点；播放头在片段开头时向后创建，接近边界或前一个关键帧时缩短。同一终点再次点击只定位已有动画。添加后进入终点编辑状态，关闭自动动画也可直接调整效果，支持撤销。

动画面板的“自定义动画”卡片可以拖到片段内部，以落点为终点创建动画，落点按工程帧率对齐。悬停时显示目标高亮、插入范围和终点时间；拖到音频、锁定或隐藏的对象不会添加。拖到画布对象时，以当前播放头为终点。

片段动画以箭头显示起止区间：左侧小圆点为开始，右侧大圆点为结束，箭头长度对应动画时长。点击圆点可定位开始或结束，点击箭身可定位结束；正在编辑的动画箭头显示黄色。选中片段且播放头位于终点时，结束圆点显示红色。

点击起点或终点会进入该关键帧的编辑状态，鼠标显示带起止标记的双向箭头，属性面板显示“编辑动画起点”或“编辑动画终点”。此时修改位置、缩放、不透明度、旋转，或在画布中拖动和缩放图片、视频，只修改选中的关键帧，无需开启“自动动画”。例如在起点将图层放到左边，再点击终点放到右边，就会形成从左到右的动画。手动移动播放头、开始播放、选择其他片段或点击“退出”会结束该编辑状态。

拖动左侧圆点可调整开始时间，拖动右侧圆点可调整结束时间；拖动箭身可整体移动动画，保持动画时长。拖动会按工程帧率对齐并修改实际关键帧时间，不移动片段本身；关键帧不能跨过相邻关键帧或超出片段边界，动画至少保留一帧。每次拖动可整体撤销，锁定轨道时不可调整动画。

相同变换之间的普通静止间隔不显示箭头；使用“添加动画”创建的动画会保留箭头，即使尚未设置不同的起止属性，也能定位、拖动和编辑。片段裁切或拆分后，箭头只显示保留的动画区间；如果真实起点或终点在片段之外，裁切边界不会显示成新的起止圆点。动画创建方式见 [画布与动画](CANVAS.md)。

自动动画默认持续 1 秒，结束位置为当前播放头；不同动画可保留间隔。已有相连箭头也可通过向右拖动后一段的起点，或向左拖动前一段的终点来拆开。点击后一段起点时，会定位并放大前一段的终点；修改效果会同步静止间隔，后一段的结束状态保留。第一个动画起点编辑片段初始属性，编辑圆点放大，退出编辑后恢复。

## 动画右键菜单

选中末尾圆点或修改该终点的属性时，圆点会播放放大、回落动效；连续调整时会完成当前动效，退出编辑后平滑恢复普通尺寸。编辑后一个动画起点时，反馈显示在实际被修改的前一个动画终点。

右键箭头可剪切、复制、删除动画，或通过“启用缓冲”选择自动、指数缓入/缓出、线性、跳跃、回弹。自动保持原有平滑曲线；跳跃会越过目标后收敛，回弹模拟弹跳。缓动随工程保存、变速及动画拖动保留，画布预览和 MP4 导出使用同一曲线。

选中动画时，Ctrl/⌘ + X 剪切、Ctrl/⌘ + C 复制、Delete 删除该动画，片段和媒体保留。复制后，选中目标片段并将播放头放到空闲动画区间，Ctrl/⌘ + V 从当前时间开始粘贴相同的运动变化、时长与缓动；不会覆盖已有动画或越过片段结尾。删除动画后，其区间保持起点状态，后续动画保留。所有修改支持撤销，锁定轨道禁止剪切、删除和缓动修改。

素材右键菜单保留片段操作，已移除淡入、缩放、滑入动画预设入口。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| 空格 / 左右方向键 | 播放暂停 / 逐帧移动 |
| Ctrl/⌘ + 左右方向键 | 前一个媒体 / 后一个媒体 |
| Ctrl/⌘ + 加号 / 减号，或 Ctrl/⌘ + 滚轮 | 缩放鼠标所在的画布或轨道区域 |
| Ctrl/⌘ + K | 在播放头处拆分所选片段 |
| Ctrl/⌘ + Alt + I | 拼接所选媒体 |
| Ctrl/⌘ + Shift + 反斜杠 | 移除全部拼接 |
| Delete / Shift + Delete | 删除 / 波纹删除 |
| Ctrl/⌘ + A / G / Shift + G | 全选 / 组合 / 解组 |
| Ctrl/⌘ + C / V | 复制片段 / 粘贴片段、图片或视频 |
| Ctrl/⌘ + Z / Shift + Z | 撤销 / 重做 |
| Ctrl/⌘ + S / Shift + S | 保存 / 另存为 |
| Ctrl/⌘ + O / I / E | 打开 / 导入媒体 / 导出视频 |
| Ctrl/⌘ + Shift + F9 | 全局停止录制 |
