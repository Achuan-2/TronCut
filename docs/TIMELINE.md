# 时间线

## 通用轨道

轨道不区分文字、视频或音频类别，统一显示为“轨道1、轨道2……”，任何轨道都可以放置不同类型的片段。编号从底部开始，新增到顶部的轨道使用下一个编号。旧工程打开后统一使用编号，片段、动画及轨道的隐藏、静音和锁定状态保留。

粘贴新增图片会为每张图片在顶部创建独立轨道，放到当前播放头位置，已有片段保持原位。

## 片段编辑

按住 Ctrl/⌘ 或 Shift 点击片段进行多选。组合后的片段会一起选择与移动，复制粘贴保持相对位置。

波纹删除只关闭删除区间中没有其他片段占用的时间，锁定轨道保持原位。滚动轨道时，顶部时间刻度尺保持可见。

## 动画起止箭头

片段动画以箭头显示起止区间：左侧小圆点为开始，右侧大圆点为结束，箭头长度对应动画时长。点击圆点可定位开始或结束，点击箭身可定位结束；正在编辑的动画箭头显示黄色。选中片段且播放头位于终点时，结束圆点显示红色。

点击起点或终点会进入该关键帧的编辑状态，鼠标显示带起止标记的双向箭头，属性面板显示“编辑动画起点”或“编辑动画终点”。此时修改位置、缩放、不透明度、旋转，或在画布中拖动和缩放图片、视频，只修改选中的关键帧，无需开启“自动动画”。例如在起点将图层放到左边，再点击终点放到右边，就会形成从左到右的动画。手动移动播放头、开始播放、选择其他片段或点击“退出”会结束该编辑状态。

拖动左侧圆点可调整开始时间，拖动右侧圆点可调整结束时间；拖动箭身可整体移动动画，保持动画时长。拖动会按工程帧率对齐并修改实际关键帧时间，不移动片段本身；关键帧不能跨过相邻关键帧或超出片段边界，动画至少保留一帧。每次拖动可整体撤销，锁定轨道时不可调整动画。

相同变换之间的静止间隔不显示箭头。片段裁切或拆分后，箭头只显示保留的动画区间；如果真实起点或终点在片段之外，裁切边界不会显示成新的起止圆点。动画创建方式见 [画布与动画](CANVAS.md)。

自动动画默认持续 1 秒，结束位置为当前播放头；不同动画可保留间隔。已有相连箭头也可通过向右拖动后一段的起点，或向左拖动前一段的终点来拆开。点击后一段起点时，会定位并放大前一段的终点；修改效果会同步静止间隔，后一段的结束状态保留。第一个动画起点编辑片段初始属性，编辑圆点放大，退出编辑后恢复。

## 动画右键菜单

右键箭头可剪切、复制、删除动画，或通过“启用缓冲”选择自动、指数缓入/缓出、线性、跳跃、回弹。自动保持原有平滑曲线；跳跃会越过目标后收敛，回弹模拟弹跳。缓动随工程保存、变速及动画拖动保留，画布预览和 MP4 导出使用同一曲线。

选中动画时，Ctrl/⌘ + X 剪切、Ctrl/⌘ + C 复制、Delete 删除该动画，片段和媒体保留。复制后，选中目标片段并将播放头放到空闲动画区间，Ctrl/⌘ + V 从当前时间开始粘贴相同的运动变化、时长与缓动；不会覆盖已有动画或越过片段结尾。删除动画后，其区间保持起点状态，后续动画保留。所有修改支持撤销，锁定轨道禁止剪切、删除和缓动修改。

素材右键菜单保留片段操作，已移除淡入、缩放、滑入动画预设入口。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| 空格 / 左右方向键 | 播放暂停 / 逐帧移动 |
| S / Delete / Shift + Delete | 拆分 / 删除 / 波纹删除 |
| Ctrl/⌘ + A / G / Shift + G | 全选 / 组合 / 解组 |
| Ctrl/⌘ + C / V | 复制片段 / 粘贴片段、图片或视频 |
| Ctrl/⌘ + Z / Shift + Z | 撤销 / 重做 |
| Ctrl/⌘ + S / Shift + S | 保存 / 另存为 |
| Ctrl/⌘ + O / I / E | 打开 / 导入媒体 / 导出视频 |
| Ctrl/⌘ + Shift + F9 | 全局停止录制 |

编辑文字时，Enter 换行，Esc 或 Ctrl/⌘ + Enter 结束编辑，详见 [文本](TEXT.md)。
