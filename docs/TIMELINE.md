# 时间线

## 通用轨道

轨道不区分文字、视频或音频类别，统一显示为“轨道1、轨道2……”，任何轨道都可以放置不同类型的片段。编号从底部开始，新增到顶部的轨道使用下一个编号。旧工程打开后统一使用编号，片段、动画及轨道的隐藏、静音和锁定状态保留。

粘贴新增图片会为每张图片在顶部创建独立轨道，放到当前播放头位置，已有片段保持原位。

## 片段编辑

按住 Ctrl/⌘ 或 Shift 点击片段进行多选。组合后的片段会一起选择与移动，复制粘贴保持相对位置。

波纹删除只关闭删除区间中没有其他片段占用的时间，锁定轨道保持原位。滚动轨道时，顶部时间刻度尺保持可见。

## 动画起止箭头

片段动画以箭头显示起止区间：左侧小圆点为开始，右侧大圆点为结束，箭头长度对应动画时长。点击圆点可定位开始或结束，点击箭身可定位结束。选中片段且播放头位于终点时，结束圆点显示红色。

拖动左侧圆点可调整开始时间，拖动右侧圆点可调整结束时间；拖动箭身可整体移动动画，保持动画时长。拖动会按工程帧率对齐并修改实际关键帧时间，不移动片段本身；关键帧不能跨过相邻关键帧或超出片段边界，动画至少保留一帧。每次拖动可整体撤销，锁定轨道时不可调整动画。

相同变换之间的静止间隔不显示箭头。片段裁切或拆分后，箭头只显示保留的动画区间；如果真实起点或终点在片段之外，裁切边界不会显示成新的起止圆点。动画创建方式见 [画布与动画](CANVAS.md)。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| 空格 / 左右方向键 | 播放暂停 / 逐帧移动 |
| S / Delete / Shift + Delete | 拆分 / 删除 / 波纹删除 |
| Ctrl/⌘ + A / G / Shift + G | 全选 / 组合 / 解组 |
| Ctrl/⌘ + C / V | 复制片段 / 粘贴片段、图片或视频 |
| Ctrl/⌘ + Z / Shift + Z | 撤销 / 重做 |
| Ctrl/⌘ + S / Shift + S | 保存 / 另存为 |
| Ctrl/⌘ + O / I / E | 打开 / 导入媒体 / 导出视频 |
| Ctrl/⌘ + Shift + F9 | 全局停止录制 |

编辑文字时，Enter 换行，Esc 或 Ctrl/⌘ + Enter 结束编辑，详见 [文本](TEXT.md)。
