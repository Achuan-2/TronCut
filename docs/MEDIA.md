# 素材与录屏鼠标

## 导入与粘贴

点击“导入媒体”可添加视频、音频和图片，双击素材将其加入时间线。复制图片、截图或视频文件后，在编辑器中按 Ctrl/⌘ + V，可直接导入并添加到当前播放头处。

截图或图片像素直接读取系统剪贴板并保存为 PNG，不启动 Windows 文件列表读取助手。粘贴和拖入素材时，顶部显示“正在添加素材…”，不弹出全屏等待；重复触发不会在同一次导入未结束时添加多份。导入失败会提示错误并恢复，之后仍可继续添加。

从系统剪贴板粘贴图片、截图或视频时，优先使用完全没有素材的最顶层轨道；该轨道有片段、已锁定或已隐藏时，在顶部新增轨道。素材从当前播放头开始。批量粘贴逐个判断，第一项加入后，后续项使用独立新轨道。

在文本输入框中粘贴时，保留文本输入框的正常粘贴行为。编辑器内复制的片段可按 Ctrl/⌘ + V 粘贴，多个片段之间的相对位置会保留。

## 跨工程素材库

媒体 Tab 分为“项目媒体”和“素材库”。项目媒体随当前工程保存；素材库在本机独立保存常用视频、音频和图片，可在其他工程中继续使用。

在“素材库”页选择当前库，通过“管理”菜单创建新库、重命名或删除库，默认库不能删除。点击“导入到库”添加文件，也可在“项目媒体”中右键素材，选择“添加到素材库…”。入库时复制文件并保留录屏鼠标轨迹，原始文件不受影响。

双击库中素材可添加到当前播放头，拖到时间线则按落点添加，同时自动加入项目媒体。项目媒体和素材库均支持搜索、缩略图与列表视图。素材库不显示类别筛选和分组下拉框，保留文件夹管理。

项目媒体顶部可筛选视频、音频或图片，分组下拉框可选择“按类别分组”“不分组”或“自定义文件夹”。点击底部“新建文件夹”，将素材拖入文件夹，或右键选择“移至文件夹”；右键文件夹可重命名或删除，删除文件夹仅将内容移回未分组。文件夹随工程保存，支持撤销与重做。

项目媒体中，Ctrl/⌘ 点击切换多选，Shift 点击连续选择，Ctrl/⌘ + Shift 点击追加连续选区。右键已选素材保留多选，可批量添加到时间线、删除或移至文件夹。批量添加按当前列表顺序，从播放头依次排列；整批添加或删除可一次撤销。删除移除工程素材及引用片段，保留硬盘原文件；有锁定引用时整批取消。

点击底部“新建文件夹”，或在空白处右键新建文件夹；右键文件夹可新建子文件夹、重命名或删除。点击文件夹可展开/折叠，将素材拖到文件夹标题即可归入其中，拖到“库根目录”可移出文件夹。搜索会查找各级文件夹和素材，并自动展开匹配项所在的层级。删除文件夹时，其中的素材和子文件夹会移回库根目录。

库中素材右键支持添加到播放头位置、删除、重命名、导出资产，以及“复制到”和“移动至”目标库子菜单。复制在目标库根目录创建独立副本；移动成功后移除源库记录和文件。重命名保留素材内容和录屏鼠标轨迹。删除库或移除库中素材前需要确认，已加入工程的素材和时间线片段仍会保留。

“导出库…”将文件夹层级、库清单、素材文件及鼠标轨迹打包为 ZIP；“导出资产…”仅打包选中的素材及其元数据。两者都可在另一台设备上通过“导入压缩库…”恢复。同名导入会创建带序号的新库，保留已有库；旧版无文件夹的压缩包仍可导入。当前 ZIP 导出总大小上限约为 4 GB，较大的素材库需要拆分导出；这里只接受 TronCut 导出的素材库压缩包。

## 外部文件拖入时间线

从资源管理器或 Finder 将图片、视频、音频文件拖入时间线，可直接导入并在鼠标落点处添加。拖入时高亮目标轨道，并显示落点时间；可一次拖入多个文件，它们从同一时间开始，优先使用目标轨道，占用冲突的素材会放入其他空闲轨道，没有空闲轨道时新增轨道。锁定轨道不接收文件。外部拖入按鼠标指定的轨道放置。

中文文件名和带空格的路径可直接拖入，无须先导入素材库。不支持的文件类型会跳过，损坏文件会显示导入错误；添加成功后选中新素材，整批添加可一次撤销。拖到时间线以外不会让窗口跳转到文件内容。

## 素材重链接

项目素材离线时，在“项目媒体”双击该素材并选择新的文件位置。原片段的时间位置和动画设置会保留。

## 媒体右键菜单

缩略图和列表视图均可右键操作素材：

| 菜单项 | 行为 |
| --- | --- |
| 添加到时间轴播放头所处位置 | 从当前播放头添加素材，并选中新片段。 |
| 替换时间轴上所选的媒体 | 替换所选的同类型媒体片段，保留时间位置、源区间、时长、动画与效果。 |
| 更新 | 重新选择文件，更新该素材及全部引用，包括组合内片段；保留片段名称和剪辑设置。 |
| 删除 | 从工程移除素材及其引用片段，保留硬盘原文件，支持撤销。 |
| 在时间线上选择 | 返回主时间线，选中引用该素材的全部片段，并定位到最早的引用。 |
| 添加到素材库… | 将当前素材独立复制到选定库，供其他工程复用。 |

更新和替换会检查素材类型及使用的源区间；新文件过短或相关轨道锁定时不会修改工程。更新、替换和删除均支持撤销与重做。

## 录屏鼠标属性

Windows 录制进行中使用绿色虚线标示录制区域。录制窗口时边框跟随窗口位置和大小，窗口最小化时隐藏；暂停时保留边框，结束或录制失败后清除。边框不抢焦点、不拦截鼠标，并从录制画面中排除；原生和兼容录制共用此提示。

录制设置中可选择“屏幕或窗口”或“自定义范围”。自定义范围在当前来源所在屏幕上打开实时框选，可在框外拖动重画、框内拖动移动、拖动八个边角缩放，也可输入 X/Y 和宽高（物理像素）；按 Enter 或“使用此范围”确认，Esc 取消。多屏时先选择所需屏幕，再框选范围；单个区域限定在一个屏幕内。H.264 录制的宽高按偶数像素对齐，最多缩小 1 像素。原生引擎在 GPU 上直接裁切后编码，独立鼠标轨迹按区域换算，区域外鼠标隐藏；兼容模式在停止时裁切并编码所选区域，长录屏保存可能需要更长时间。录制期间绿色虚线标出实际选区。

点击“开始录制”后，TronCut 主窗口在倒计时前自动最小化。倒计时仅在屏幕顶部显示小提示，不遮暗桌面、不抢焦点，鼠标点击可穿透，可正常操作其他应用，按 Esc 取消。录制 TronCut 自身窗口时主窗口保持显示，倒计时期间也可正常编辑。倒计时结束后在录制屏幕底部中央显示独立、可拖动的置顶录制控制窗口，提供计时、暂停/继续和停止，并保留任务栏入口；录制窗口且无法确定所在屏幕时，控制窗显示在编辑器所在屏幕。点击“显示编辑器”可在录制期间正常操作 TronCut。编辑器顶部“录制控制”按钮可重新唤出控制窗，并将其移回屏幕内。录制设置和控制条不会覆盖在编辑器内部，Windows 控制窗口启用录屏排除。录制结束、倒计时取消或启动失败时自动恢复编辑器；也可用 Ctrl/⌘ + Shift + F9 停止录制。关闭控制窗口会停止并保存录制。录制设置的标题与关闭按钮固定在顶部，滚动到下方设置后仍可直接关闭。

录屏组合提供“录屏”“画面”两个属性标签，录屏在前。录屏页的录屏样式、圆角倒角、鼠标样式和自动缩放均可独立展开或收起，鼠标大小、颜色、点击高亮和平滑移动在“鼠标样式”中调整。画面页提供位置、缩放等参数，选中时间线动画端点时自动切到画面页。取消组合后，画面和独立鼠标恢复各自的属性标签。保存工程时，鼠标轨迹随素材归档。

背景和鼠标样式的下拉菜单同时显示名称与缩略预览，收起后保留当前选择的预览；支持方向键、Home/End、Enter 选择，Esc 关闭菜单。留白与圆角可以先清空再输入，空值或越界值不会写入工程，失焦恢复上一次有效值。新录屏轨道按摄像头、画面、麦克风和背景排序；旧录屏取消组合时修正独立轨道的顺序，保留共用轨道的位置。

控制窗采用 272×42 的单行工具条，仅保留计时、暂停/继续、停止、显示编辑器和最小化图标。窗口在倒计时期间后台预加载，Windows 原生录制引擎同时预先初始化设备和编码器，倒计时结束后才启动采集与媒体时钟，倒计时期间的画面和声音不会写入录制；取消时清理预备进程与空文件。倒计时结束即显示控制窗；少数设备仍未就绪时显示“准备中”，暂停与停止暂不可用，就绪后开始计时。可拖动左侧把手移动；悬停按钮查看说明。点击最小化会收起到任务栏，录制继续进行，可从任务栏或编辑器顶部“录制控制”按钮恢复。

新录屏文件、素材和片段默认按本地开始录制时间命名，例如“录屏 2026-10-16 15-30-20-123.mp4”；末尾三位为毫秒，用于区分同秒录制。Windows 原生录屏与兼容录屏均使用此规则，已有工程的名称保留。

## 录屏自动美化

录制窗口的“录屏完成后自动美化”默认开启透视网格背景和自动缩放，圆角默认为 0（直角）。背景下拉框提供“无背景”、透视网格和四种渐变背景，选中后立即预览；还可设置留白、圆角、鼠标样式与大小，以及 1.5～3 倍放大。开始录制或关闭录制窗口时会保存选项，重启后继续使用。旧版 Recordly 壁纸设置自动迁移为透视网格；已保存在工程中的背景素材保留。

静态背景中的“透视网格（黑）”采用黑底灰线，网格向远处收拢并逐渐变密。背景按画布尺寸生成，预览、导出和保存的工程均可使用。

录制结束后，画面、背景、摄像头和麦克风自动组成一个录屏对象，时间线上只显示一个条目。选中后默认打开“录屏”属性页，可直接通过下拉框更换背景，修改留白、圆角、鼠标以及自动缩放范围，无需重新录制。对象的移动、裁剪和拆分保持内部素材同步，样式更改支持撤销和保存重开。

在“录屏”属性页、时间线右键菜单或“编辑”菜单选择“取消组合”，即可展开为独立片段。背景、画面、镜头和声音保留原始素材及已有动画，可以分别编辑。录后修改只作用于当前录屏对象，下一次录制仍使用录制窗口保存的默认值。

Windows 原生录制根据鼠标点击生成缩放，并在放大时平滑跟随鼠标移动。可选择仅录屏缩放或背景一起缩放，动画端点和时间可继续编辑；调整背景、圆角或鼠标不会重写镜头路径。重新设置自动缩放或放大倍数会按原始轨迹重新生成镜头。没有有效鼠标轨迹或交互时不生成动画。兼容录制支持背景美化，但鼠标已经包含在画面中，无法单独修改或生成自动缩放。

时间线按镜头实际运动显示箭头：放大、平移、反向平移和缩小分别成段，停顿期间留空；悬停箭头可查看动作类型和时间。密集弹簧采样保留在箭头内部，仍可编辑端点、调整时长、复制和删除。旧版按两段合并的录屏也会按实际路径显示，已有镜头数据不会因此被重写。
