# 素材与录屏鼠标

## 导入与粘贴

点击“导入媒体”可添加视频、音频和图片，双击素材将其加入时间线。复制图片、截图或视频文件后，在编辑器中按 Ctrl/⌘ + V，可直接导入并添加到当前播放头处。

截图或图片像素直接读取系统剪贴板并保存为 PNG，不启动 Windows 文件列表读取助手。粘贴和拖入素材时，顶部显示“正在添加素材…”，不弹出全屏等待；重复触发不会在同一次导入未结束时添加多份。导入失败会提示错误并恢复，之后仍可继续添加。

从系统剪贴板粘贴图片、截图或视频时，优先使用完全没有素材的最顶层轨道；该轨道有片段、已锁定或已隐藏时，在顶部新增轨道。素材从当前播放头开始。批量粘贴逐个判断，第一项加入后，后续项使用独立新轨道。

在文本输入框中粘贴时，保留文本输入框的正常粘贴行为。编辑器内复制的片段可按 Ctrl/⌘ + V 粘贴，多个片段之间的相对位置会保留。

## 外部文件拖入时间线

从资源管理器或 Finder 将图片、视频、音频文件拖入时间线，可直接导入并在鼠标落点处添加。拖入时高亮目标轨道，并显示落点时间；可一次拖入多个文件，它们从同一时间开始，优先使用目标轨道，占用冲突的素材会放入其他空闲轨道，没有空闲轨道时新增轨道。锁定轨道不接收文件。外部拖入按鼠标指定的轨道放置。

中文文件名和带空格的路径可直接拖入，无须先导入素材库。不支持的文件类型会跳过，损坏文件会显示导入错误；添加成功后选中新素材，整批添加可一次撤销。拖到时间线以外不会让窗口跳转到文件内容。

## 素材重链接

素材离线时，在素材库双击该素材并选择新的文件位置。原片段的时间位置和动画设置会保留。

## 录屏鼠标属性

含鼠标轨迹的录屏片段在属性面板中提供“视频”和“鼠标”两个标签页。鼠标样式、大小、颜色、点击高亮和平滑移动位于“鼠标”页，可独立于视频画面调整。保存工程时，鼠标轨迹随素材归档。
