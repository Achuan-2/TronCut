# 字幕断句、精修与 AI 模型

通过“编辑 → 首选项 → AI 模型”配置服务。先添加服务，填写名称、API 基础地址和密钥，再点击“获取模型列表”；搜索模型名称后，可勾选多个模型并一次添加。同一服务下的模型共用地址和密钥，可以在“当前使用的模型”中切换。没有模型列表接口的服务也可以手动填写模型 ID。点击“测试连接”验证当前服务的模型，再点击“确定”保存。

模型列表按 [List models 接口约定](https://developers.openai.com/api/reference/resources/models/methods/list) 从服务的 `/models` 获取。聊天接口兼容 Chat Completions，可使用云端服务或提供兼容接口的本地模型。地址填写 API 基础路径（例如包含 `/v1` 的地址），软件会追加 `/chat/completions`；也支持填写完整的 Chat Completions 地址。密钥通过系统安全存储加密保存在应用数据目录，不会进入项目，也不会在再次打开首选项时返回界面。更换服务来源后需要重新填写密钥。旧配置会保留原有模型和密钥。

请求字段使用 [Chat Completions 接口约定](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create) 的 `model`、`messages` 和非流式响应。交互参考 SmartSub 的“断句与精修”，实现代码与设置存储独立于 SmartSub。

在字幕面板右上角选择“语音转文本”，可设置“断句与精修”：

| 设置 | 行为 |
| --- | --- |
| 标准断句（默认） | 按标点和长度拆分，默认约 22 字，不需要 AI。 |
| AI 语义断句 | 使用所选 AI 寻找语义断点，校验字词和标点完整保留。 |
| 自定义字数上限 | 在 8–120 范围内设置每条长度，保留完整英文单词及句尾标点。 |
| 不限制长度 | 保留原语音段，不再按长度或句子拆分；仍保留真实语音停顿。 |
| AI 纠错精修 | 纠正明显识别错误、同音错字和标点，尽量保留口语。 |
| AI 润色 | 轻度调整表达，使语句通顺，要求保留原意、事实、数字和专名。 |

断句方式和文字精修独立设置，也可添加补充要求。点击“开始识别”会记住本次设置，识别全时间线并新建字幕轨道。默认不调用 AI；主动启用 AI 断句或精修后，字幕文本会发送至首选项中的服务，音视频仍在本地识别。

Qwen3-ASR 当前只提供语音段时间，缺少逐字时间时，拆分出来的段内起止点按文本长度估算，不代表强制对齐结果。处理不会跨过原语音段的静音间隔。“不限制长度”不取消 VAD 分段。

已有字幕也可从右上角菜单选择“AI 精修与润色”。有选中的字幕时处理选中项，否则处理全部未锁定字幕。此入口只修改文字，保留片段数量、时间和样式；一次操作可以整体撤销。任务执行期间修改或锁定的字幕不会被返回结果覆盖。

AI 返回条目缺失、ID 错误、断句改写原文、精修明显删减/扩写或服务请求失败时，对应批次保留规则结果或原文并提示。取消任务会中止操作，不写入部分结果。AI 修正仍需要人工核对，尤其是专业术语和事实性内容。

验证命令：

```powershell
pnpm exec vitest run tests/caption-processing.test.ts tests/preferences.test.ts
pnpm build
node scripts/smoke-ai-captions.mjs
```

桌面专项脚本使用本机临时 HTTP 服务验证接口、首选项、密钥加密保存、润色、撤销和服务失败回退，不向实际云端发送字幕。它证明协议与交互链路，不代表任何具体云端模型的文本质量。
